# 奶睿pro

> B 站页面布局与视觉优化扩展 · **v1.2.1**

> 顶栏重做（含视频页半顶栏）、播放页满宽排版、全屏 / 图片开合动效、iOS 毛玻璃材质、
> 搜索面板与首页信息流优化、功能轮盘。

设置入口：**B 站任意页面右下角的 ⚙ 按钮**（工具栏图标不再弹窗，点它走浏览器自己的扩展菜单）。

## 一、功能总览

设置面板分八组：**动效增强 / 高级材质 / 界面优化 / 功能增强 / 快捷功能 / 个性设置 / 实验室 / 新版本改动**。最后一组不是开关，是本版本「用户能体验到的改动」清单（文案在 `modules/whatsNew.ts`）。再往后原本还有一页「开源地址」（仓库 / 许可证 / 上游项目的跳转，没有开关），1.1.6 起暂时收起（代码保留，见 `settingsPanel.ts` 的 `ABOUT_VISIBLE`）。下表是全部功能，`key` 列是内部开关标识（开发用）。

**1.1.6 v011 起搜索框 / 搜索面板 / 触发面板三块默认关闭**（弹出来的浮层用实色底更清楚），
顶栏、评论区图片、轮盘背景仍默认开。
