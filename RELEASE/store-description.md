## 详细说明

```
专门给细节控用的 B 站改造包。

只要你在 B 站上看到设计不合理的地方 —— 顶栏对不齐、播放页两侧空一大片、卡片大小不能调、
滚动条多出一条、某个按钮根本不该在那儿、加载时抖一下 —— 都可以往这里加。

功能：

1. 顶栏重做：整条顶栏自己画，第一帧就在，不用再等 B 站那套 header 脚本（播放页要 1.2 秒、冷缓存 4~5 秒）
2. 播放页半顶栏：顶栏只画在右栏上方，播放器直接顶到窗口最上面，左边整块留给画面
3. 播放页满宽排版：播放器吃掉右栏之外的全部宽度，标题 / UP 主 / 操作栏 / 简介按经典版顺序排在下面
4. 顶栏搜索：下拉里带搜索历史、热搜和联想词，结果在新标签页打开，原来那页不被打断
5. 首页优化：去掉大 banner、频道栏和顶部轮播，番剧 / 直播 / 赛事这些特殊卡不进推荐流
6. 卡片大小无级调节：首页、搜索页、播放页右栏三个位置分开存，220~380px 随便拖，窗口越宽多排一列
7. 搜索页优化：把写死的 7 列栅格换成和首页同一套，左右留白不再占掉小半个屏幕
8. 卡片整体化：整张卡片都能点，不用再瞄准标题那两个字
9. 卡片边界：首页 / 搜索页 / 播放页三个位置各一个开关，想要描边就有
10. 夜间模式：B 站自己没管的地方一起补上（顶栏、搜索框、浮层、卡片描边），站内换页被改回去会自动补
11. 毛玻璃材质：顶栏、评论区图片、搜索框、搜索面板、悬停浮层、设置面板、轮盘背景，每块单独开关
12. 材质无级调节：模糊强度 / 遮罩强度 / 背景明暗三条滑块，顶栏还有「上实下透」的渐变
13. 功能轮盘：按住 Tab 弹出圆盘，八个方向八个功能，松手就走；键位和格子都能改，键盘党可以直接按 1~8
14. 快速设置面板：按 ` 键直接开关设置面板，不用每次都把鼠标挪到右下角点 ⚙
15. 动效：网页全屏、宽屏、评论区图片开合都有过渡，不再硬切
16. 操作浮钮收纳：返回顶部 / 刷新 / 设置三颗可以自动隐藏、半隐藏或胶囊化
17. 悬停预取：指针在卡片上停 80ms 就把目标页预取下来，点进去几乎是瞬间
18. 掐掉埋点与广告投放：首页请求 177 → 110，播放页 204 → 164（回一个「假成功」，不留骨架）
19. 播放页首屏快约 350ms：布局改成「先读完再统一写」，不再反复强制同步排版
20. 首帧前先显示封面：黑屏从 1.5 秒缩到 1 秒左右（B 站自己已经不做 poster 了）
21. 一堆「就差一格」的修复：顶栏和内容对齐、搜索页多出来的那根滚动条、非半顶栏时的白缝、
    数字藏品头像的 UP 主卡片胖一圈、大窗口下多余的「展开更多」……

设置入口：B 站任意页面右下角的 ⚙。每一项都能单独关掉 —— 不喜欢的部分，一个字节都不会改你的页面。

说明：顶栏改造在个人空间、历史记录、直播页会整体退出（这些页面没有统一的全局顶栏），
动效类功能不受影响。

欢迎来提交功能建议，只要需求不离谱，不出意外可以火速上线。
```
