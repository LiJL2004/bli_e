# 奶睿pro v1.0.4

> 这一版集中在三块：**首页**（屏蔽推荐流广告、加载占位重新打磨）、
> **顶栏与夜间**（渐变衔接更自然、夜间覆盖全站）、**动态页**（入口收纳进左栏，
> 作为实验室功能提供，默认关闭）。

## 商店更新说明（可直接粘贴）

```
1.0.4 更新内容：

· 首页：推荐流中的广告卡片不再显示
· 首页：加载占位卡片的样式与排版更统一，加载期间不再出现空白格
· 顶栏：渐变过渡更自然，顶栏与页面内容的衔接更柔和
· 夜间模式：同时启用站点原生深色主题，视频、搜索、个人空间等页面均生效
· 设置：滑块与开关的白色圆钮加大，操作更易点中
· 优化页面滚动时的资源占用，减少卡顿
· 实验室新增「动态页优化」：把右侧横幅与顶部编辑器收进左栏（默认关闭，可在实验室中开启）
```

## 完整更新内容

### 新增

- **首页广告屏蔽（默认开启）**：推荐流里的推广卡片（封面右下角带「广告」角标的）
  不再显示，栅格自动回填，不留空格。

### 变更

- **顶栏渐变**：顶栏与页面内容的衔接改回带遮罩的渐变 —— 白纱与背景模糊一起淡出，
  过渡段从 44% 起步、走 S 形曲线铺满余下高度，模糊退到 0 的过程中没有突变点，
  不再出现一条硬边。夜间同步使用同段位的深色渐变。

- **夜间模式**：在开启扩展夜间的同时启用站点原生深色主题，首页、动态页、视频页、
  搜索页、历史记录、个人空间六类页面均生效；站内切换页面（不重载文档）时主题被换回
  亮色会自动补回。关闭时只还原扩展改动过的部分，不影响用户自己开启的站点夜间。

- **首页加载占位**：占位卡片恢复 1.0.3 的斜向渐变观感，并补上卡片底色与圆角，
  让占位格与真实卡片在形状上保持一致；加载期间不再出现纯白空格，
  卡片流尾部也不会留出整片空白。骨架数量随实际列数自适应。

- **设置面板控件**：滑块圆钮 14px → 16px、开关圆钮 20px → 24px，四周留边收至 1px，
  圆钮与蓝色填充边缘几乎相切，不再像浮在槽里。

### 实验室

- **动态页优化（默认关闭）**：把右侧「社区中心」横幅与顶部「发动态」编辑器收进左栏用户
  卡片底部的两个竖排按钮，版面还给动态流。三栏布局、动态流列数、卡片外观都保持原样；
  两个原入口不搬动节点，只是隐藏后由按钮代理点击，站点改版时最多是代理失效，不会丢节点。
  1.0.4 起从「界面优化」移进实验室并默认关闭 —— 它改的是整页版面，先观察一个版本；
  未开启时也不会向动态页注入任何样式。

### 优化

- **降低页面滚动时的主线程占用**：评论区图片查看器与首页卡片流的元素扫描逻辑改用更轻的
  查询方式；首页空壳卡片的判定改为先查特征元素、命中即返回。

- **移除重复的动画常量**：图片开合的时长与缓动曲线原本在三处各写一份，改为单一来源，
  避免后续改动不同步。

---

**安装方式**：解压后在浏览器扩展管理页「加载解压缩的扩展」指向解压目录；
或直接安装同目录下的 `bili-elite-1.0.4.zip`（与送审包为同一份产物）。
