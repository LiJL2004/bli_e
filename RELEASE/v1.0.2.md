## 完整更新内容

### 新增

* **高级材质 → 顶栏触发面板材质（默认关闭）**：悬停顶栏「首页」弹出的频道面板，以及右侧
头像 / 消息 / 动态 / 收藏 / 历史的悬停浮层，可以统一换成毛玻璃。两个滑块的默认值
**38px / 61%** 与「搜索面板材质」一致（都是顶栏上弹下来的大面板，观感要统一），
但各自独立存储，改一个不影响另一个。
* **新增「实验室」分类**（在「个性设置」下面）：放的是实验性开关，后续可能转正、可能长期
留着、也可能直接删掉。全部**默认关闭** —— 它们改的是观感与手感，出问题会影响整站。

  * **夜间模式**：深色顶栏（`#1a1b1f` 渐变 + 白 8% 描边）、深色搜索框与面板卡片
（`#202226`），强调色提到 `#6fb0ff` 保证深底上的对比度。只换顶栏 / 搜索框 /
搜索面板 / 顶栏浮层这几块我们本来就在管的表面，不动 B 站正文。
  * **浮动键胶囊化**：悬停时右下角两枚圆键向左展开成带文字的胶囊（返回顶部 / 刷新）；
点「返回顶部」时按钮边缘画一圈滚动进度，到顶自动收掉。
  * **材质开关过渡**：材质开关一开原来是硬切，现在底色走 200ms 过渡，模糊随着底色变透
被慢慢露出来。
  * **全屏关闭动画**：从「动效增强」搬到这里，仍然默认关闭。
* **动效增强 → 面板卡片级联（默认开启）**：打开设置面板时卡片按 18ms 递增淡入 + 上移 4px；
面板本身的开合动画一点不动，卡片这段做得更软（420ms 缓出 + 40ms 起步延迟），
叠在缩放上不打架。

### 变更

* **设置面板整体改版**：① 左侧分类加线性图标；② 数值从灰字改成可点的胶囊，点一下直接
敲数字，不用拖滑块微调；③「恢复默认」与版本号抽成面板底部的固定操作条，不再挤在
「个性设置」页末尾。底部操作条里开发版本号在左、「恢复默认」在右。
* **「背景明暗」的显示值与编辑值统一**：胶囊上写的是「偏暗 6」这种偏离量，点开输入框原来
却显示原始值 44。现在输入框显示 6、提交时再换算回 44 —— 点开看到的就是胶囊上那个数字。

### 优化

* **播放页首屏不再出现 B 站旧版顶栏**：播放页在 Vue 接管前会先渲染一版旧顶栏，以前我们只把
它的内容 `visibility:hidden`（留一条白条）。它带着一层毛玻璃，整页首屏渲染期间一直在重算
背景模糊 —— 现在**整块 `display:none`**，首屏这段由骨架栏（只画 logo、实色底、不做模糊）
填住，新版顶栏一到一起退场。
* **字标改为 base64 内联**：顶栏 logo 原来用 `i0.hdslb.com` 上的 PNG 做 mask，首屏实测会请求
两次（其中一次花了 386ms），这段时间 logo 位置是空的。现在把这张 6.4KB 的图内联成
CSS 变量（只存一份，四条 mask 声明共用），首帧就有字标，也不再依赖 B 站 CDN。
* **首屏少读一次布局**：浮动键的滚动监听改成 `load` 之后再挂 —— 加载期间 B 站会打出大量
scroll 事件，每次同步都要读 `window.scrollY`，会把待处理的布局强制 flush。
实测首屏脚本时间：搜索页 100ms → **17ms**，首页 65ms → **≈15ms**。
* **首屏主线程**：`MutationObserver` 的回调在每个 DOM 批次上都会跑，首屏 B 站会打出成百上千批。
两处无谓开销砍掉：① 顶栏出现后不再每批都 `querySelector('.bili-header')`；② 预加载哨兵只有
首页才有，没有哨兵时整段遍历（实测最坏占首屏脚本时间 60%）直接跳过。
* **悬停顶栏「首页」的反馈**：加上和「动态」同款的跳动动画（B 站只给普通导航项加了 `jump`，
首页被排除在外），旁边的下拉箭头同时做 180° 翻转；面板展开、鼠标移进面板后箭头保持朝上。
* **数值胶囊点开输入框不再「两个盒子交叉淡入」**：改成胶囊自己变色（浅蓝 → 白 + 一圈蓝描边），
文字错开淡入淡出，两层几何完全重合。

### 修复

* **频道面板在毛玻璃下闪一下**：淡入原来挂在外层的 `opacity` 上，而外层一旦 `opacity < 1`
就成了「背景根」，卡片上的 `backdrop-filter` 只能采到背景根内部（空的）—— 整段淡入期间
玻璃**没有模糊**，到 `opacity` 归 1 那一帧才突然糊上。现在淡入挂到卡片自己身上。
* **右侧「消息 / 动态 / 收藏 / 历史」的悬停浮层在毛玻璃下闪烁**：B 站给这几个浮层用的是
Vue 过渡类（300ms），动的是**外层** `.v-popover` 的 `opacity` 和位移 —— 同一个「背景根」
问题，而且 300ms 比设置面板更长，看着更闪。现在过渡期间把外层 `opacity` 钉成 1
（位移保留，滑动还在），淡入挪到卡片自己身上，曲线和时长跟 B 站那条对齐。
* **设置键点在圆盘边缘没反应**：`:active` 会把按钮缩到 88%，点在边缘时指针落到缩小后的盒子
外面，浏览器把 `click` 判给公共祖先 —— 表现正是「按下去有动画、松手没反应」。
给按钮加一层透明的 `::after` 命中区（外扩 6px）。
* **网页全屏时设置键盖在视频上面**：进网页全屏后 B 站给 body 加的是 `position: fixed`，
播放器那套 `z-index: 100000` 被关在 body 这个层叠上下文里；我们的宿主挂在 `<html>` 下，
只要 z-index 是正数就永远压在整棵 body 之上。现在盯 body 的 class，**进全屏把宿主整个
藏起来**，退出恢复 —— 视觉上就是「被视频盖住」。
* **首页「返回顶部」后点「刷新」，预加载不再自动加载**（下滑一下才恢复）：`IntersectionObserver`
只在**相交状态变化**时回调，刷新后哨兵仍然不相交，回调不触发。现在信息流一有增删就打个
脏标记，下一次同步强制重建观察器。
* **鼠标悬停顶栏「首页」展开面板时没有动画**：原来是 `display: none ↔ block`，`display`
不可过渡。改成 `visibility` + `opacity` + `translateY(-6px)` 的过渡（160ms 淡入 +
200ms 带回弹的位移）。
* **数值胶囊点开输入框比胶囊宽一圈**：输入框宽度取的是 `getBoundingClientRect()`，那个值会被
面板的等比缩放一起放大（默认 130%），写进 `style.width` 之后比胶囊宽出 30%、往左探出去一截。
改用布局像素的 `offsetWidth` + `border-box`，两边完全重合。
