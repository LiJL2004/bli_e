# 奶睿pro v1.1.6 · 应用商店更新说明

> 粘贴到商店后台的「更新说明 / What's new」字段。纯文本，约 380 字，在 Chrome Web Store 的
> 1000 字符限制以内。下方代码块里的内容可整段复制。

```
1.1.6 更新内容：

· 全新自绘顶栏（默认开启）：整条顶栏由扩展自己画，打开页面第一帧就完整，
  不再等 B 站那套 header 脚本（实测播放页要 1.2 秒、冷缓存 4~5 秒）
· 右侧图标悬停浮层：头像 / 消息 / 动态 / 收藏 / 历史，未读消息数直接显示在图标上
· 视频页半顶栏（默认开启）：顶栏只画在右栏推荐流上方，播放器顶到窗口最上面，画面更大
· 悬停预取：鼠标在卡片上停 80ms 就把目标页预取好，点进播放页快约 450ms
· 卡片整体化：整张卡片除 UP 主名字外都能点，悬停标题不再单独变蓝
· 搜索框 / 搜索面板重做：搜索历史 + 热搜 + 输入联想，↑↓ 选择、Enter 搜索
· 头像浮窗收窄到 260，三行菜单居中；删掉重复的「主题」一行（夜间模式在设置里改）
· 实验室精简：删掉「全屏关闭动画」「动态页优化」「材质开关过渡」三项
· 修复：番剧 / 纪录片 / 影视等特殊播放页被「播放页优化」改坏（现在这类页面不做改动）
· 修复：夜间模式在其它标签页关不干净（顶栏回来了、页面还是黑的）
· 修复：开半顶栏后播放器右侧一条 1px 黑边
· 修复：切浮层 tab / 收藏夹时擦除动效不生效
```
