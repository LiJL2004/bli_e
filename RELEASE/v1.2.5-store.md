# 奶睿pro v1.2.5 · 应用商店更新说明

> 粘贴到商店后台的「更新说明 / What's new」字段。纯文本，约 600 字，在 Chrome Web Store 的
> 字符限制以内。下方代码块里的内容可整段复制。

```
1.2.5 更新内容：

· 图片查看器重做：动态页、视频与动态的评论区、专栏等所有图片入口统一使用新的查看器，
  支持 50%~800% 缩放、放大后拖拽、左右旋转与一键复位，底部工具栏实时显示当前缩放比例
· 查看器支持左右滑动切换图片，横向拖动超过一定距离即切换，滑到两端会回弹；
  左右箭头与键盘方向键同样触发切换动画
· 图片打开时先用页面上的缩略图占位、再逐级换成更清晰的版本，不必对着空白等待
· 个人主页的侧边分类、排序筛选与「播放全部」统一为设置面板那套胶囊样式，
  侧边按钮靠右排列、与右侧内容对齐
· 搜索页顶部的分类标签改为文字标签页样式，底部指示条随切换平滑滑动
· 播放页的播放器新增 12px 圆角（窗口态 / 宽屏 / 小窗生效，全屏保持直角）
· 首页卡片的「已关注」标签改为「已订阅」式胶囊，带勾选图标
· 设置面板与顶栏浮层的按钮统一为涟漪动效
· 动态页点击相册缩略图直接打开大图，不再经过中间那层工具栏
· 修复：动态悬浮窗视频开头被跳过、悬浮窗没有声音、播放器圆角黑角与弧线虚线、
  搜索页分类标签下划线叠加、动态页点评论区误弹悬浮窗、顶栏浮层点视频时当前页重复弹悬浮窗
```
