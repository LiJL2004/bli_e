# 奶睿pro v1.1.3 更新公告

> **一句话**：宽屏也有动画了（可单独关）；视频进入宽屏 / 网页全屏 / 全屏时轮盘不再抢键；
> 设置面板的开关把「点下去鼓一下」的手感找回来；轮盘选中的页面默认开在新标签页。
> 顺带修掉三个「看起来像没生效」的问题：开关点了没反馈、绑过按键后轮盘失灵、后退回来不在原位。

送审包：`bili-elite-1.1.3.zip`（204 KB / 14 个文件 / `manifest.json` 在 zip 根目录）。

---

## 新增 · 宽屏模式动画

播放器右下角那个「宽屏」不再瞬间撑开：进入时从原尺寸长到铺满版面宽度（280ms），
退出时缩回去（240ms），与网页全屏同一套曲线，右栏跟着让位。

开关在 **设置 → 动效增强 → 宽屏模式动画**，默认开。它和「网页全屏动画」是两条独立的路 ——
宽屏只把播放器撑宽、不接管整屏，两条时间线也互不重叠（只在普通 ↔ 宽屏之间播，
进出网页全屏 / 全屏各走各的）。不想要就关掉，回到瞬切。

## 新增 · 轮盘默认在新标签页打开

以前轮盘选中哪一格就在当前标签页跳过去，现在默认开在**新标签页并自动切过去** ——
视频看到一半用轮盘去「历史 / 动态」，不会再把当前这个视频顶掉。
新标签页插在当前页右边，不是甩到标签栏最末尾。

想回到原来的行为：**设置 → 快捷功能 → 更改默认值为当前标签页打开**（默认关）。

## 新增 · 设置面板呼出快捷键

快捷功能页多了一张卡：按一下键盘左上角那颗 `` ` `` 打开设置面板，再按一下关掉，
不用每次都把鼠标挪到右下角点 ⚙。全站生效，光标在输入框里时不接管；按键可以改（默认 `` ` ``）。

## 变更 · 全屏 / 宽屏时轮盘不接管

视频进入**宽屏 / 网页全屏 / 全屏**之后，呼出键不再弹出轮盘，这次按键原样还给浏览器
（全屏里的 Tab 本来就该是焦点导航）。退出之后下一次按键自动恢复 —— 判定是每次按键现算的，
不存在「退出了但还记着全屏」的状态。轮盘开着时进了这几种模式会直接收起。

## 变更 · 三处文字说明收进感叹号

「呼出功能轮盘」右边、「卡片大小」与「预加载范围」的标签右边各多一颗**灰色感叹号**，
鼠标悬停弹出说明。原来那三段灰字不再白占行高，也不用每次开面板都读一遍。

键盘也能拿到：按 **Tab** 走到感叹号上，提示卡同样弹出、圆圈带一圈焦点环，
读屏则直接念出说明内容（之前只有鼠标悬停这一条路）。

## 修复 · 开关切换时的放缩被悬停动画吃掉

上一版给开关加了悬停动效之后，点开关时那一下「鼓起来」被整段盖掉了（两条动画抢同一个属性，
鼠标又必然停在开关上）。现在位置、悬停、按下与切换各占一个属性，互不打断：
点开关拇指会重新鼓一下，悬停和按下的手感都保留。

## 修复 · 绑定按键后关面板，轮盘呼出键会失灵

在设置面板里点「呼出按键」进入等待状态、然后直接把面板关掉，绑定状态没被清干净：
**轮盘从此不接管呼出键**，而且下一次任意按键（包括在评论区打字）都会被当成「正在绑定」
吃掉，静默改成新的面板呼出键。

现在关面板时两颗按键的绑定态一起清，按键监听里也补了一道兜底（面板没开着就说明是残留，就地复位）。
顺带：两颗呼出键不小心设成同一个时，会把旧键自动交给对方，两边都还能用 —— 以前是面板那颗静默失效。

## 修复 · 「当前标签页打开」后退回来不在原位

开着「更改默认值为当前标签页打开」时，从轮盘跳走再按后退，以前会回到一个停在顶部的页面。
现在离开前记下滚动位置与文档总高度，回来后按回去。

**说清楚做不到的那一半**：后退仍然是一次整页重新加载 —— B 站自己关掉了 bfcache
（首页注册了 unload 监听，另有一批 beforeunload 与常驻心跳连接），这一层是站点的，扩展改不了。

同时修了一个让它**只在跨域时生效**的问题：那条记录原本在目标页就被删掉了，
所以「视频页 → 首页 / 番剧 / 历史」这类同源跳转一直没还原过，只有跳去动态 / 空间 /
消息 / 直播才碰巧有效。

## 更新方法

1. 下载 `bili-elite-1.1.3.zip`
2. **覆盖解压**到你现在放扩展的那个目录（路径不要变，浏览器记的就是这个路径）
3. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`），找到「奶睿pro」，点「重新加载」
4. 回到 B 站刷新页面。右下角齿轮 → 面板底部应显示 `1.1.3`

> 首次安装：解压到固定目录（别删，浏览器每次启动都从这里读）→ 打开扩展管理页 →
> 开启「开发人员模式」→ 把解压出来的文件夹拖进去。
