# 奶睿pro v1.1.4 · 应用商店更新说明

> 粘贴到商店后台的「更新说明 / What's new」字段。纯文本，约 480 字，在 Chrome Web Store 的
> 1000 字符限制以内。下方代码块里的内容可整段复制。

```
1.1.4 更新内容：

· 新增「播放页优化」（界面优化，默认开启）：播放页改成满宽，标题、作者、点赞那一排按经典版
  排到播放器下方，播放数据与简介合成一张卡片，标签变成标题后的 #话题 链接
  （想回到原版布局：设置 → 界面优化 → 播放页优化，关掉即可）
· 新增「操作浮钮」收纳：右下角那列按钮可自动隐藏（鼠标贴到屏幕右边缘才滑出）或半隐藏，
  也能设置成收起时保留「返回顶部 / 刷新」
· 新增广告与运营推广位屏蔽（默认生效）：播放页右栏的推广卡、推荐流里的运营推荐、
  左栏评论上方的活动横幅一并摘掉
· 首页与搜索页左右留白收窄，卡片相应变大（1920 宽下留白 88 → 46px）
· 修复：功能开关只在当前页面生效、刷新或新开标签页会退回默认值
· 修复：切换窗口大小时顶栏有概率变成一整条白
· 修复：播放页优化的停顿重播、信息加载慢、作者头像空白等问题
· 修复：弹幕发送框偏大，以及从网页全屏回到窗口态后发送框消失
```
