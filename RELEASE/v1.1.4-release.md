# 奶睿pro v1.1.4 更新公告

> **一句话**：播放页默认换成满宽排版 —— 标题、作者、点赞那一排都挪到播放器下方，播放数据与
> 简介合成一张卡片；右下角那列操作浮钮可以收起来了；右栏和左栏的运营推广位默认摘掉。
> 顺带修掉一个影响所有人的问题 —— 以前改过的开关只在当前页面生效，刷新就退回默认值。

送审包：`bili-elite-1.1.4.zip`（212 KB / 14 个文件 / `manifest.json` 在 zip 根目录）。

---

## 新增 · 播放页优化（默认开启）

开关在 **设置 → 界面优化 → 播放页优化**，**默认开启**。

它原本是「实验室」里的 beta。这一版把整套排版跑完了一轮实测（下面「修复」一节列了修掉的问题），
不再是「试一试」的东西，所以转正、改名、默认打开 —— 想回到原版布局就在面板里把它关掉，
关掉之后页面一个字节都不改。

**开了之后**，播放页从「居中 + 两侧各空一大块」变成满宽，信息区按经典版播放页重排：

- 1920 窗口下左右留白从 178px 收到 11px，播放器从 1123px 宽长到 1290px（高度跟着到纯 16:9）。
- **标题 / 播放数据 / 作者 / 点赞那一排全部挪到播放器下方**，打开页面第一眼就是视频。
  标题独占整行，长标题和一串话题能自然折行。
- **播放数据与简介合成一张浅灰卡片**：播放量 / 弹幕数 / 发布时间压在卡片顶部，下面是简介。
- **标签变成标题后面的蓝色 `#话题` 链接**，原来简介下面那排灰色胶囊不再重复占一行。
- **作者行压成一行**：头像 / 名字 + 关注 / 粉丝数，「充电」与「发消息」去掉。
  点赞 / 投币 / 收藏 / 分享那一排挪到作者行右边，底下那条灰线一起去掉。
- **右栏**去掉「推荐 / 最近上传 / 番剧 / 影视…」那条分类条，宽度跟着窗口伸缩；
  推荐卡封面放大到右栏宽度的 58%（约 1.8 倍），鼠标停上去的内联预览也一起撑满。
- **弹幕发送栏搬进播放器控制栏中间**（和全屏时一样），播放器高度因此收回纯 16:9。
  发弹幕的入口还在，只是跟着控制栏一起在鼠标离开时淡出。
- 窗口窄于 1120px 时操作栏退回单独一行，不会把标题挤成一两个字。

**宽屏 / 网页全屏 / 全屏不接管** —— 那三种模式 B 站自己算一套尺寸，两边同时写会把播放器
卡在错误的大小上。进出这三种模式时自动让位、退出后收回。

## 新增 · 操作浮钮的收纳

右下角那列按钮（⚙ 设置键、返回顶部、刷新）现在可以收起来，三条开关合成一张小卡放在
**设置 → 界面优化 → 操作浮钮**，默认全关 —— 不开的话和以前一模一样。

- **自动隐藏**：鼠标不靠近屏幕右边缘时，整列滑出屏幕；移到右边缘 20px 内滑回来。
  滑出延迟 100ms（只是路过右边缘去拖滚动条时不该弹出来）、收回延迟 600ms。
  鼠标压在按钮上时永不收回。
- **自动隐藏时始终显示操作按钮**：收起时只收走设置键，「返回顶部 / 刷新」留在原位 ——
  滚到页面中部想随手点「返回顶部」时，不用再去蹭屏幕边缘。
- **半隐藏**：平时只露出右半边并压暗到 60%，鼠标移上去完全展开。

**自动隐藏与半隐藏互斥**，后打开的那个生效，另一个自动关掉。设置面板开着时暂停收纳
（⚙ 滑走了、面板还杵在屏幕上会很怪），关掉面板后按原状态收起。

## 新增 · 广告与运营推广位屏蔽（默认生效，没有开关）

播放页上这几处运营投放现在一并摘掉：

- 右栏顶上那张推广卡（B 站广告位的统一外壳 `.ad-report`）、右下角浮出来的 banner；
- 推荐流里插的「运营推荐」小卡（360×80，指向别的视频或课堂课程）；
- 左栏评论上方那条 102px 高的浅蓝色活动横幅（「分享科学科普内容，赢丰厚奖金！」那一类）。

**它不属于播放页优化**：那个开关关掉、页面退回原版布局时同样屏蔽。也不需要设置 ——
推广位和稿件内容无关，每期活动换一张图，没什么可选的。

## 变更 · 首页 / 搜索页的左右留白

两侧留白从 `88~132px` 收到 `32~72px`：1920 窗口下 88 → 46px，2560 下 118 → 61px。
多出来的宽度交给卡片栅格（1920 下卡片 348 → 365px，2560 下多排一列）。
卡片大小滑块的默认值也同步调到 340px —— **没动过这个滑块的会自动跟着变大，动过的保留你的值**。

## 修复 · 开关只在当前页面生效，刷新就退回默认值

1.1.3 里所有功能开关都存不进去：写的时候按 `{ videoBeta: true }` 这样平铺写，读的时候却按
`{ 'bili-elite-settings': {...} }` 整包取，两边对不上。

于是**每一次刷新、每一个新标签页，所有开关都回到默认值**。默认开着的那批没人察觉；
默认关的一眼就看出来 —— 比如「播放页优化 明明开了，刷新后又自己关了」。

现在整包写回（约 300 字节）。如果你之前一直在忍「改了又变回去」，是这个原因。

## 修复 · 缩放窗口后顶栏有概率变成一整条白

首屏那条白色骨架栏原来只靠 CSS 条件退场：导航项一不在就重新露出来。而 B 站的顶栏导航是
**按窗口宽度响应式重建**的（实测缩放时导航项数量在 10 → 8 → 10 之间跳），重建的那一帧里
导航项可能是 0 个，骨架栏就重新盖到真顶栏上 —— 于是整条顶栏变白、导航和搜索框全不见。

现在改成一次性退场：真顶栏的导航项第一次出现时就把骨架栏永久撤掉，之后无论顶栏怎么重建
都不再露出来。

## 修复 · 播放页优化的一批问题

- **视频会「停顿重播」一次**：根因是搬动作者卡片的时机太早，B 站还在水合期，会当成异常把
  整棵子树重挂、连带把播放器销毁重建。实测 2.8s 之后才安全，现在统一等到 3.0s。
- **`#话题` 要等两三秒才出现、作者头像一直空白**：B 站的首屏白屏检测期（约 3s）里往它的树里
  插节点会触发整页重渲染、连顶栏一起变白条，所以那段时间只敢用 CSS。等待期左栏不是空的 ——
  照 B 站官方的样子画了灰色占位骨架（灰圆 + 灰条 + 灰按钮），内容到位时原地换掉，实测不跳。
- **作者头像空白**：B 站的懒加载只在元素可见时才把图片地址落到 `src` 上，而这块面板搬过来
  之前一直是隐藏的，等它变可见时观察器早退场了。现在搬完手动补一刀。
- **带头像框的作者行特别高**：B 站给带头像框的 UP 主把头像容器撑到 80×80，整行从 48 变 80。
  现在头像框不显示，尺寸按无头像框的原样钉回 48。
- **「已关注」按钮上残留粉丝数**：B 站给已关注态多加了一层容器，我们按老结构拆不出来。
- **充电按钮的占位和实际尺寸不一致**（老版稿件用的是另一套实现）。
- **简介的「展开更多 / 收起」不见了**：之前用 CSS 把简介压成 2 行，B 站量出来的高度变矮，
  判定「这篇简介不需要折叠」，原版按钮就不渲染了。现在折叠状态、高度、按钮全交回 B 站，
  我们只加「点灰卡任意位置也能展开」。
- **简介卡下面的投票 / 评分卡和简介卡贴在一起**（两张同色灰卡 0 间距，看着像糊成一张）。
- **直播页画面不显示**：这套样式里有播放器的公共类名，直播页也被套上了。现在只对
  `video` 与番剧播放页生效。

## 修复 · 弹幕发送框偏大 / 网页全屏回来后消失

- 窗口态把发送栏搬进控制栏时，尺寸照抄了全屏那套，压进 35px 高的控制栏里又高又长。
  现在长相同原版、尺寸收一档：30px 高、最宽 560px、发送键 56×30，「弹幕礼仪」保留。
- 从网页全屏切回窗口态时 B 站会把控制栏整块重建，我们的搬运拿不到新节点就放弃了，
  发送框于是留在被隐藏的容器里 —— 表现为「发送框没了」，而且不是每次都能复现。
  现在搬不动就重试，每次屏幕状态变化都重新接管一次。

## 更新方法

1. 下载 `bili-elite-1.1.4.zip`
2. **覆盖解压**到你现在放扩展的那个目录（路径不要变，浏览器记的就是这个路径）
3. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`），找到「奶睿pro」，点「重新加载」
4. 回到 B 站刷新页面。右下角齿轮 → 面板底部应显示 `1.1.4`

> 首次安装：解压到固定目录（别删，浏览器每次启动都从这里读）→ 打开扩展管理页 →
> 开启「开发人员模式」→ 把解压出来的文件夹拖进去。
