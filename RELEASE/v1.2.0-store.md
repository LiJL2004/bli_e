# 奶睿pro v1.2.0 · 应用商店更新说明

> 粘贴到商店后台的「更新说明 / What's new」字段。纯文本，约 499 字，在 Chrome Web Store 的
> 1000 字符限制以内。下方代码块里的内容可整段复制。

```
1.2.0 更新内容：

· 三页白边统一成同一条 10px：首页 / 搜索页 / 播放页不再各宽各的
· 掐掉 B 站的埋点上报、广告投放、播放器质量上报：首页请求 177 → 110，播放页 204 → 164
· 播放页首屏快约 350ms：布局改成「先读完再统一写」，不再反复强制同步排版
· 播放页首帧前先显示封面（B 站自己不做 poster）：黑屏从 1.5 秒缩到 1 秒左右，
  悬停卡片时还会顺手预取这张封面，点进去更快看到画面
· 顶栏的首页 / 动态 / 消息 / 收藏 / 历史 改成在右侧新标签页打开，当前页不被打断
· 首页大 banner 的 28 张图层图不再下载，首页再少 30 个请求（banner 保留静态底图）
· 首页首屏不再「震」一下：滚动条常驻 + 楼层卡提前摘除，整屏重排从 0.126 降到 0.064
· 首页卡片加载增加过渡：骨架换真卡时淡入 + 上浮 8px，不再硬切
· 修复夜间模式：加载中的白卡、楼层卡的白边、骨架上的扫光
· 修复：关掉「首页优化」后首页无限刷新
· 修复：页面合成的 keydown 事件让全屏动画的按键监听抛错
```
