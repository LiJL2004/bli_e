# 奶睿pro v1.1.2 更新公告

> \*\*一句话\*\*：多了一个「按住 Tab 弹轮盘」的快捷入口 —— 八个方向各放一个页面，松手即达。
> 顺带把轮盘的进出场动画、第一次呼出的掉帧、浅色页面上的可读性全部重做了一遍。

送审包：`bili-elite-1.1.2.zip`（201 KB / 15 个文件 / `manifest.json` 在 zip 根目录）。

\---

## 新增 · 快捷功能：功能轮盘

设置面板从五组变成六组，新的一组成「快捷功能」，位置在**界面优化**和**个性设置**之间。

**怎么用**：在首页 / 动态页 / 视频页按住 **Tab**（可改绑），屏幕正中展开一枚圆盘。
指针指向哪一格，圆盘中间就显示那一格的名字；松开呼出键直接过去。
中途不想去了，把指针停回圆盘正中的空档再松手就是取消 —— 不用再点一次。
键盘党可以直接按 **1–8** 选格，**Esc** 退出。

**八个方向是固定的**，和你装了什么无关：顶部首页、右上番剧、右消息、右下收藏、
底部动态、左下历史、左个人主页、左上直播。卸下某一格只会把它清空、位置本身不会消失 ——
练出手感之后闭着眼也知道第几格是什么。

**每一格都能换**：设置 → 快捷功能 → 轮盘项目「编辑」。左边点位置、右边点功能就装上去；
那格已经有东西时是替换（两边都有东西则交换）。「卸下」清空当前格，功能随时能再装回来。

**已经在那一页**时选它只会收起轮盘，不会重新加载页面。

图标与顶栏用的是同一套（信封 / 风车 / 星星 / 时钟），每格图标下面写着名字，
没装东西的格子只画一个虚线占位圈。

## 新增 · 「轮盘背景」材质

「高级材质」里多一张卡，只控制**轮盘外那层全屏虚化**（模糊 19px / 暗度 16% 起，
两个滑块实时预览、可恢复默认）。

轮盘本体的材质（八片花瓣 + 中心圆）是写死的，不参与调节 —— 中心圆里要读两行字，
材质不该有「调坏」的可能。这样无论背景调到多糊或多透，名字始终读得清。

## 改了什么（手感与视觉）

* **进出场重做**：展开约 290ms（放大 + 淡入 + 八格顺时针依次弹出），
收回约 200ms 一口气缩掉。进场减速、退场加速，是 iOS 那套手感。
* **收回不再「卡」**：上一版最后 120ms 画面其实是**静止**的 —— 轮盘只缩了 6%、
八格图标却已经淡完，然后轮盘瞬间消失。现在缩放和淡出同时进行，
所有元素在同一条时间线上收尾，没有静止的尾巴。
* **第一次呼出不再掉帧**：全屏毛玻璃的着色器要到第一次真正上屏才编译，实测掉了 60ms。
现在页面空闲时就把轮盘建好、把那层模糊预渲染一遍（1% 不透明度，看不见），
第一次按 Tab 也是顺的。
* **浅色页面上更好读**：花瓣的渐隐提前到外三分之一，外缘和八条缝隙一起化进背景，
不再是「到外缘还是实心、缝隙就是八条硬辐条」；中心圆的投影改成小偏移低浓度，
圆周围那圈灰环没有了；名字加到 12px 并加了三层白晕，深底浅底都读得清。
* 跟随夜间模式换色；「减少动态效果」下退化为纯淡入淡出（不做缩放与位移）。

## 生效范围

|页面|能否呼出|
|-|-|
|首页、动态页|可以|
|视频页、番剧播放页|可以|
|其它页面|不可以|

其它页面上 Tab 是浏览器的焦点导航键，抢过来会毁掉键盘操作，所以先不接；
后续会按需扩页面。设置面板开着、或者光标在输入框里时也不会接管。

## 更新方法

1. 下载 `bili-elite-1.1.2.zip`
2. **覆盖解压**到你现在放扩展的那个目录（路径不要变，浏览器记的就是这个路径）
3. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`），找到「奶睿pro」，点「重新加载」
4. 回到 B 站刷新页面。右下角齿轮 → 面板底部应显示 `1.1.2`

> 首次安装：解压到固定目录（别删，浏览器每次启动都从这里读）→ 打开扩展管理页 →
> 开启「开发人员模式」→ 把解压出来的文件夹拖进去。
