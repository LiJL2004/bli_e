# 奶睿pro v1.0.0

> 首个公开版本。把 B 站网页端整体重画一遍：顶栏、搜索面板、首页信息流、播放页右栏，
> 再加上 iOS 风格的毛玻璃材质与几段克制的转场动画。

- **适用**：Chrome / Edge（Chromium 内核）与 Firefox，Manifest V3
- **设置入口**：B 站任意页面右下角的 ⚙ 按钮（工具栏图标弹窗里也有同一份开关）
- **实时生效**：所有开关、材质参数改完立刻生效，无需刷新；「恢复默认设置」一键回退

## 动效增强

- **全屏关闭动画**（默认关）：退出原生全屏（F）时，播放器从全屏位置平滑落回页面内位置，不再硬切
- **网页全屏动画**：进入 / 退出网页全屏各一段过渡，播放器与页面一起伸缩
- **评论区图片动画**：点开图片从缩略图位置 FLIP 放大到全屏，关闭时缩回原位；动态页「查看大图」同款

## 高级材质（毛玻璃）

五处材质各自独立开关，模糊强度与遮罩强度都能拖：**评论区图片背景**、**顶栏**、
**搜索框**、**搜索面板**、**设置面板**。遮罩拉到 0 时材质完全透明，发丝描边与投影一起淡出。

## 界面优化

- **首页优化**：去掉首页大 banner / 频道栏 / 顶部轮播；隐藏封面与操作区两枚「稍后再看」浮钮；
  把番剧、直播、赛事、课堂等特殊卡从推荐流里移除并修正行距
- **搜索面板优化**：搜索历史 / 热搜下拉改版 —— 历史固定 4 行可滚动、去掉「展开更多」、
  弹出与收回带过渡
- **卡片边界 / 卡片确认**：首页、搜索页、视频页右栏各一对，六个开关互不影响
- **首页预加载**：把加载哨兵上抬，提前取回下方的推荐内容，滑到底不再等白屏（范围 0–300% 可调）
- **播放页右栏留白收起 / 顶部提示条收起**：两处占位块按需收起，版面更紧凑
- **设置面板缩放**：面板整体 80–140% 等比缩放

## 始终开启（没有开关）

- **顶栏重做**：自绘 logo 与骨架栏，重排导航 / 搜索框 / 右侧头像区；搜索页把搜索框并入顶栏中央
- **顶栏下拉面板**：顶栏「首页 ∨」的频道下拉整体重绘，悬停展开、内容按需注入（首屏不解析）
- **吸顶子栏让位**：页面级 sticky 子栏自动下移到固定顶栏之下，不再被压住
- **播放页右栏广告屏蔽**：隐藏弹幕列表下方那块 `#slide_ad` 广告卡
- **首页加载占位**：B 站骨架卡重绘为更接近成品卡片的占位格

## 已知限制

- **个人空间**（space.bilibili.com）、**历史记录**、**直播站**保持 B 站原版顶栏 ——
  这些页面没有统一的全局顶栏，硬套会出现「凭空多一条白栏」
- 登录 / 账号页、手机版不注入
- 动效类功能（全屏 / 图片动画）不受上面两条影响
