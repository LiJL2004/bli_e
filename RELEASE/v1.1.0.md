# 奶睿pro v1.1.0

> 本版是修瑕疵的一版：首页刚打开时那半秒的空白补上了加载占位，高级材质下动态浮层里的
> 两块白底也清掉了；另外「设置面板材质」改为默认关闭，其余材质照旧。

## 商店更新说明（可直接粘贴）

```
1.1.0 更新内容：

· 首页：刚打开时还没加载出来的区域不再是一片空白，补上加载占位
· 高级材质：动态浮层里「最新动态 / 历史动态」的白底消失，与毛玻璃统一
· 设置：设置面板材质默认关闭，需要的话可在「高级材质」里手动开启
```

## 完整更新内容

### 修复

- **首页首屏的空白**：刚打开首页的一瞬间，第一批卡片下面原来是一整片白 —— 首屏那 10 张卡
  是站点直接吐出来的，站点自己那批骨架要等前端启动完（约 0.7–1.4s）才插进来，中间这段
  空档里栅格下面是空的；「首页优化」把轮播藏掉、列数交给自适应之后，宽屏上 10 张卡只排得
  满两行，空档接近半屏。现在空档期会补一批和原生骨架卡同构的占位（几何完全照抄原生骨架，
  真骨架到位时不跳），原生骨架一插进来就自动撤掉。

- **高级材质下的白底**：开「顶栏触发面板材质」时，动态浮层里「最新动态 / 历史动态」两个
  分组标题是两块白板 —— 站点是用标题的不透明白底去盖分隔线中间那段的。现在白底去掉、
  分隔线拆成两侧各一段，标题和毛玻璃融为一体。

### 变更

- **设置面板材质默认关闭**：它是唯一一块盖在设置面板上的材质，而面板要长时间读数值、拖滑块，
  毛玻璃透出底下的内容反而更累。其余五块材质仍然默认开启。
  之前手动开过的会保留自己的选择，需要的话在面板里关一次或点「恢复默认」。

---

**安装方式**：解压后在浏览器扩展管理页「加载解压缩的扩展」指向解压目录；
或直接安装同目录下的 `bili-elite-1.1.0.zip`（与送审包为同一份产物）。
