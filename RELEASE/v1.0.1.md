> 设置面板新增「个性设置」分类。

## 完整更新内容

### 性能

- **首页信息流扫描改为「按类名过滤 + 每秒最多一次」**：原来滚动时每 200ms 扫整页 9000+ 个节点、
  逐个 `getComputedStyle()` 强制样式重算 —— 实测把空闲主线程占用从 0.6% 拉到 24%。
  现在先用类名关键字过滤一遍（9000 → 一两百），整体再节流到每秒一次。
- **骨架占位去掉常驻扫光动画**：卡片里的骨架在内容加载完后不会从 DOM 消失（只是塌成 0×0），
  却常驻 60 个无限动画。现在卡片骨架保留静态渐变，动画只留给尾部楼层骨架；
  1.0.1 收尾时进一步实测（空闲主线程 23.7% → 6.5%），把这最后 9 个动画也去掉了，
  只留一层 120° 的柔和渐变。
- **首页预加载的哨兵检查从常驻轮询改为 `IntersectionObserver`**：只有哨兵进入「视口底部 + 200px」
  时才开那个补发 `scroll` 的定时器，离开即停，不在底部时开销为零。

### 界面

- **新增「个性设置」分类**（与「界面优化」并列）：奶睿设置键、奶睿顶栏图，
  以及原来的「设置管理 → 恢复默认设置」都收到这一页。
- **奶睿设置键**（默认关）：右下角悬浮球由 ⚙ 换成奶睿形象，铺满圆盘的黄光，尺寸与原版一致（44×44）。
- **奶睿顶栏图**（默认关）：顶栏左上角字标换成电视造型的奶睿插画（48×38，位置与原字标对齐）。
- **右下角新增「返回顶部 / 刷新」两枚浮动键**（白底黑图标，挂在设置键上方）：
  返回顶部全站可用、滚过 200px 才出现；刷新只在首页出现，走 B 站自己的「刷新内容」逻辑，
  只重取推荐流、不重载整页。按页面类型给键，没有的键不占位。
- **原生浮动按钮收进设置**：新增「原生刷新按钮屏蔽」（首页「刷新内容」+ 信息流「换一换」）、
  「原生返回顶部按钮屏蔽」（首页 / 搜索页 / 视频页「顶部」+ 动态页「回到顶部」）；
  「…」三点菜单与「客服」默认隐藏，不再出现在右下角。
- **动态页隐藏「回到旧版」按钮**：动态页右侧那枚旧版入口不再显示，「回到顶部」保留。
- **移除工具栏弹窗**：点工具栏图标不再弹出开关面板（和页面内 ⚙ 面板重复），
  改为走浏览器自己的扩展菜单 —— Edge 会直接列出「网站访问权限 / 从 Edge 中删除 / 管理扩展」等默认项。
- **设置面板最末行新增开发版本标记**（形如 `开发版本 1.0.1 v010`），便于反馈时确认构建。

### 修复

- **点「刷新」之后首页预加载不生效**：底部骨架格一直挂着、不再自动加载下一批内容。
  原因是保活定时器的触发条件漏了「哨兵在视口上方」这一种情况（哨兵被 CSS 上抬了 150vh，
  停在真实底部时它反而在视口之外），已修正。
- 选项页里「恢复默认设置」的路径文案跟着分组调整（界面优化 → 个性设置）。
