## 完整更新内容

### 新增

- **功能轮盘**：按住呼出键（默认 Tab），屏幕正中展开一个圆盘，八个方向各占一格；
  把指针指向某一格、松开呼出键就跳过去。中途不想去了，把指针停回圆盘正中的空档再松手
  就是取消 —— 一次都没选过就松手，什么都不会发生。
- **方向固定，与参考图一致**：顶部 0°、右上 45°、右 90°、右下 135°、底部 180°、
  左下 225°、左 270°、左上 315°。默认**顶部是首页、底部是动态**，八格正好装满八项
  （新增「番剧」），左右各三。

- **呼出键可改绑**：点一下「呼出按键」胶囊、再按任意键即可，Esc 取消。存的是物理键位，
  换输入法 / 大小写 / 键盘布局都不会失效。
- **轮盘编辑器**：设置面板 → 快捷功能 → 轮盘项目 → 编辑。左边是圆盘预览，右边是
  「功能入口」格子。两侧的选中互不联动：
  - 选中左侧某一格 → 点右侧功能，就用它替换这一格（该功能已在别处则两边交换）；
  - 先点右侧功能 → 再点左侧某一格，同样换过去；
  - 「卸下」清空当前选中的那一格，并取消选中，功能回到右侧列表里随时能再装。
- **键盘党友好**：轮盘开着时数字键 1–8 直接选第 N 格（空槽跳过）。
- **不抢键盘**：焦点在输入框 / 评论框里、设置面板开着、或者按着 Ctrl / ⌘ / Alt / Shift
  时，Tab 照常是原来的 Tab。

### 变更

- 设置面板从五组变成六组：**动效增强 / 高级材质 / 界面优化 / 快捷功能 / 个性设置 / 实验室**。
- 「恢复默认设置」现在也会把轮盘复位（呼出键回 Tab、八个方向回默认排布）。
- 夜间模式下，轮盘与轮盘编辑器跟面板一起换成深色（强调色 `#6fb0ff`）。
- **轮盘进出场重做**：展开约 290ms（放大 + 淡入 + 八格顺时针依次弹出），收回约 200ms
  一口气缩掉。收回时不再「慢慢缩一点点然后原地等」—— 上一版最后 120ms 画面是静止的，
  然后瞬间消失，看着就是卡住。
- 轮盘不再等第一次按下呼出键才建 DOM：页面空闲时先建好、并把那层全屏毛玻璃预渲染一遍，
  所以第一次呼出也不会掉帧（实测从掉 60ms 变成 7ms 一帧）。
- 花瓣的渐隐提前到 0.86 就开始、0.96 基本归零：外缘和八条缝隙一起化进背景，
  不再是「到外缘还是实心、缝就是八条硬辐条」。
- 中心圆的投影改成小偏移、低浓度：原来 34px 模糊 + 0.18 浓度会在圆周围糊出一圈灰环，
  看着像个灰甜甜圈。中心圆也不再叠 `backdrop-filter`（0.86 白本来就没什么可透的，
  省掉它之后缩放动画里那一层不用每帧重新采样背景）。

- 「卸下」按钮用品牌蓝而不是红色 —— 它只是把功能从轮盘上摘下来，不是不可逆的删除；
  没有选中可卸的格子时按钮是禁用的。

### 说明

- 这一版轮盘在**首页 / 动态页 / 视频页**生效（视频页含普通视频与番剧播放页）。
  其它页面上 Tab 是浏览器的焦点导航键，抢过来会毁掉键盘操作；后续版本会按需扩页面。

- 轮盘只做「跳转」，不模拟站内路由：首页与动态分属两个域名，消息中心 / 个人空间更是独立的
  子应用，整页跳转是唯一可靠的做法。
