# 奶睿pro v1.1.6 更新公告

> **一句话**：这版把**顶栏**整个换成我们自己画的 —— 打开页面第一帧就是完整的一条，
> 不再等 B 站那套 header 脚本；播放页的顶栏还缩成了「只画在右栏上方」的半条，
> 播放器因此能顶到窗口最上面，画面大一圈。

送审包：`bili-elite-1.1.6.zip`（228 KB / 15 个文件 / `manifest.json` 在 zip 根目录）。

---

## 新增 · 顶栏优化（默认开启）

以前顶栏是「等 B 站画出来，再改它」：B 站的 `bili-header.umd.js` 什么时候把顶栏渲染出来，
我们才能动手 —— 实测播放页 1.2 秒、冷缓存 4~5 秒，这段时间顶栏要么空着、要么是旧结构，
看起来就是「顶栏半天长不出来」。

这一版反过来：**整条顶栏由扩展自己画**（宿主 `#bili-elite-tb`，`document_start` 就建好），
原生那条只做 `visibility: hidden`，仍占着文档流里那 64px，所以开关来回切页面不会跳。

- **左**：logo + 「首页 ∨ / 动态」。首页那个 ∨ 悬停展开的频道面板还是原来那块，
  材质、夜间配色一套复用。
- **中**：500×40 搜索框，绝对居中。点开是搜索面板 —— **搜索历史**（三个子站共用一份，
  最多 10 条，可清空）+ **热搜** + **输入联想**（命中的字自己加粗）。
  ↑↓ 选择、Enter 搜索、Esc / 点外部 / 滚动关闭。
- **右**：头像 → 消息 / 动态 / 收藏 / 历史 → 投稿，顺序与原生一致。
  四个图标是照 B 站原样搬的 SVG（动态是四瓣风车，不是上一版那个闪电）。

## 新增 · 右侧图标的悬停浮层

头像、消息照原生做；动态 / 收藏 / 历史照 BewlyCat 的排版做。

- **头像浮窗**：头像、昵称（跟着大会员配色）、LV、硬币 / B 币、关注 / 粉丝 / 获赞三格，
  下面「个人中心 / 投稿管理 / 退出登录」。这版把宽度从 300 收到 **260**，三行改成
  **图标紧贴文字、整组居中**。
- **消息浮窗**：回复我的 / @我的 / 收到的赞 / 系统消息 / 我的消息，未读数跟在文字后面；
  顶栏图标上还有一颗蓝色未读气泡（>99 显示 99+）。
- **动态 / 收藏 / 历史**：视频卡 + 作者行；历史还带「删除这条记录」。
- 浮层开合是从图标那个角「落」下来（位移 10px + 0.98 缩放，180ms 开、120ms 关），
  不是一块白突然出现。

## 新增 · 视频页半顶栏（默认开启）

播放页的顶栏只画在**右栏推荐流上方**，左边视频那一块整条不要。

- 顶栏左边界 = **播放器右边缘**，不留缝、不留圆角，白底和右边栏连成一整块；
- logo / 首页 ∨ / 动态整排隐藏 —— 左边本来就是空的，留着只是几颗悬在视频上的字；
- 搜索框缩成 36px 高的行内块，吃掉中间剩下的宽度，塞在右侧图标前面；
- 左栏上移 **54px**（顶栏 64 − 上方留白 10），播放器顶到窗口最上面，只留 10px 空隙；
- 左右栏间距 24 → 12，省下的宽度全给播放器。

沉浸式（宽屏 / 网页全屏 / 全屏）下整条让位，一点不插手。

## 新增 · 悬停预取：点进播放页快约 450ms

鼠标在首页卡片 / 右栏推荐卡上停 80ms，就把目标页的文档 `rel=prefetch` 下来（上限 6 个）。

| | TTFB | FCP |
| --- | --- | --- |
| 直接导航 | 386 / 329ms | 830 / 721ms |
| 预取后导航 | **1 / 1ms** | **371ms** |

B 站的 HTML 没有 `Cache-Control`，普通 HTTP 缓存进不去，所以 preconnect / Speculation Rules
在这里都没用 —— 只有 `rel=prefetch` 有效。

## 新增 · 卡片整体化

整张卡片除 **UP 主名字**（要去空间，单独保留）之外，点到哪儿都跳视频。
顺带把「悬停标题变蓝」收掉：整张卡已经是一个点击目标，标题再变色就成了卡里第二个
「可点区域」的暗示。

## 变更 · 卡片悬停衬底

悬停时的灰底换成 BewlyCat 那套数值；「卡片确认」（首页 / 搜索页 / 视频页三个开关）整组删掉 ——
它只是一层纯 CSS 的悬停反馈，关掉之后卡片看着像死的，没人真的会去关。

## 变更 · 默认值

- 三个「卡片边界」（首页 / 搜索页 / 视频页）→ 默认关闭；
- 「高级材质」里的搜索框 / 搜索面板 / 触发面板 → 默认关闭（顶栏那块仍默认开）。

默认值只对**没存过该项**的用户生效（首次安装、或点「恢复默认」），手动开过的不动。

## 删除 · 六项开关（行为固定为开启）

「播放页右栏留白收起」「顶部提示条收起」「统一返回顶部键」「统一刷新键」
「原生刷新按钮屏蔽」「原生返回顶部按钮屏蔽」从面板里拿掉了 —— 都是「把 B 站那堆散落按钮
收成一套」这种没有反悔价值的整理动作，留着开关只让人多按一次。样式和实现都在，只是不再可关。

顺带：播放页右栏推荐卡悬停时那枚「稍后再看」也常驻隐藏了。

## 变更 · 实验室精简

删掉三项（都是「只在很窄的场景里生效、长期没人开」的）：

- **全屏关闭动画** —— 只在「按 F 退出原生全屏」那一刻补一段 180ms 的 FLIP，
  浏览器自己那条退出过渡本来就够用；
- **动态页优化** —— 只在 t.bilibili.com 生效、默认关闭；
- **材质开关过渡** —— 材质开关一年点不了几次，为那一次不硬切常驻一整套过渡不划算。

现在实验室只剩「浮动键胶囊化」一项。

- 头像浮窗里那行「主题: 深色 / 浅色」删掉 —— 夜间模式在「个性设置」里本来就有，

## 修复

- **番剧 / 纪录片 / 影视等特殊播放页被「播放页优化」改坏**：`/bangumi/play/ss…`、`/ep…` 这类页面
  和普通 `/video/` 页**不是同一套 DOM**（没有 `#mirror-vdcon`，也没有左右栏，播放器直接挂在
  剧集布局里），而我们的播放器尺寸规则是不分页面的 —— 一挂上去就把播放器按窗口宽度改写，
  实测同一页 `668×432` 被撑成 `1099×618`，压过右边的剧集列表。
  现在「播放页优化」只认 `/video/`，这类特殊播放页**一个字节都不碰**（悬停预取、整卡点击、
  全屏动画里的番剧分支保留 —— 它们只是动画 / 预取 / 点击代理，不改排版）。
- **夜间模式在其它标签页关不干净**：A 页开→关之后，其它标签页顶栏恢复了、页面还是黑的。
  根因是补夜间的那条回调被 `requestAnimationFrame` 排到了后台标签页，等切回来才执行，
  执行时你早关了、它又把深色挂回去。现在一律「执行时再读一次开关」，切回标签页时还会再对齐一次。
- **开半顶栏后播放器右侧一条 1px 黑边**：高度取整让容器比例和视频差了一点点，
  `object-fit: contain` 就在右边露出 0.56px 的播放器黑底。高度改成不取整，比例严格一致。
- **切浮层 tab / 收藏夹时擦除动效不生效**：原来切一下会整块重建 DOM，新节点一出生就是
  终态、没有过渡可补间。现在先就地切选中态，数据回来时只替换列表、不动头部。
- **半顶栏下 UP 主那一行整体低 64px**、压在简介卡上（v012 修）。
- **点顶栏空白处会点到下面的元素**：顶栏宿主改成自己吃事件，空白处不再透传。
