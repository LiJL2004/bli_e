## 完整更新内容

### 新增

- **顶栏导航控件的悬停光晕**：原来悬停只有文字变蓝和图标跳动，在毛玻璃底上不太显眼。
  现在悬停时多一层品牌蓝柔光 —— 自绘 logo、「首页 ∨」「动态」、右侧消息 / 动态 /
  收藏 / 历史。光晕贴着字形与图标的轮廓走，不会铺出一块方底。
  搜索框不加（它本身已经是一整块材质）；头像和投稿也不加 —— 圆形头像加光晕像「选中」，
  粉色胶囊外面套一圈蓝边更不像它自己。
- **卡片「⋮」菜单适配高级材质**：悬停卡片右下角三个点弹出的菜单，原来是一整块不透明白
  卡片，和旁边所有毛玻璃浮层不搭。现在它跟频道面板用同一套材质 —— 模糊强度 / 遮罩强度
  也共用「触发面板」那两个滑块，不再多一行设置。
- **菜单的入场不再「先硬后糊」**：这个菜单的淡入和右侧浮层是同一个毛病（淡入做在外层，
  外层半透明就成了背景根，玻璃前 300ms 完全不模糊、最后一帧才糊上）。现在外层负责位移、
  卡片自己负责淡入，从第一帧就是模糊的。
- **夜间模式同步**：夜间下这块玻璃换成深色、光晕换成夜间强调色，和其它几块材质保持一致。

### 变更

- **夜间模式转正**：「实验室 → 夜间模式」移到「个性设置」，仍然默认关闭。它是实验室里
  观察最久的一项，这版又把卡片「⋮」菜单、悬停光晕的夜间配色补齐了。
- **面板卡片级联转正**：同样移到「个性设置」，默认关闭。
- **当前页指示**：顶栏「首页 / 动态」下方多一条 2px 蓝色短横，只在首页与动态页亮。
- **材质实时预览**：材质滑块左边多一个 24×24 小方块，跟着滑块实时显示模糊 + 遮罩效果，
  调数值不用再来回开关面板。
- **尊重「减少动态效果」**：系统里关掉动画的用户（macOS / iOS「减弱动态效果」、Windows
  「关闭动画」）不会再看到大幅位移与缩放 —— 顶栏跳动、面板位移、图片放大、全屏开合都会
  变成瞬切或纯淡入。
- **圆角统一**：4 / 6 / 8 / 10 / 12 / 13 / 14 收成 4 / 8 / 12 三档。
- **动效时长统一**：全站九种时长收成三档 —— 快 160ms 给贴手反馈、常规 220ms 给面板浮层、
  慢 320ms 给收起和材质切换。（设置面板的开合动画按约定保持原样。）
- **卡片入场不再硬切**：骨架格被真卡顶掉的那一帧，真卡淡入 160ms。
- **频道面板收起不再被切掉**：位移、淡出、隐藏三个时长对齐，收得完整。
- **性能**：观察器从「整页」收窄到「顶栏 + 信息流」；设置面板样式改为第一次点 ⚙ 才注入；
  悬停光晕的文字部分改用 `text-shadow`（不再建合成层）；图片查看器 / 图片材质 / 浮动键
  挪到浏览器空闲时再装。

- **「顶栏触发面板」改名「触发面板」**：它管的不止顶栏 —— 悬停「首页」的频道面板、
  右侧头像 / 消息 / 动态 / 收藏 / 历史的浮层，再加上卡片这个「⋮」菜单，都是同一块材质。
  之前调好的模糊 / 遮罩强度不变。

### 修复

- **高级材质下「刚刚在其他设备上播放」卡片悬空一个白色菱形**：这块箭头是 B 站自己用
  `::after` 画的白方块，卡片换成毛玻璃之后它还是实心白。现在去掉了 —— 浮层本来就贴着
  「历史」，箭头没有信息量。
- **首页当前页指示条**：长度改成跟「首页 ∨」整块控件等宽（原来写死 16px，比控件短、还偏
  向箭头那侧），往下滚动进入收起态顶栏后也不会再消失。
