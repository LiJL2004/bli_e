# 奶睿pro v1.1.5 · 应用商店更新说明

> 粘贴到商店后台的「更新说明 / What's new」字段。纯文本，约 460 字，在 Chrome Web Store 的
> 1000 字符限制以内。下方代码块里的内容可整段复制。

```
1.1.5 更新内容：

· 新增「右侧推荐视频封面大小」滑块（设置 → 界面优化 → 播放页优化）：默认 320px，
  220~400 可调，卡片高度自动跟着封面走，只在这个开关打开时生效
· 多人合作投稿（创作团队）：去掉顶部「创作团队 N 人」横幅，多个 UP 主和右侧点赞那一排
  回到同一行，和标题、简介的间距跟单 UP 主时逐像素一致
· 播放页把原版「N 人正在看」挪到播放数据那一行的最右侧（之前被藏掉了，滚到评论区就看不见）
· 简介卡与评论之间补 10px 间距，不再贴在一起；简介卡收起态的悬停高亮换成暖白，
  鼠标停在「播放数据 + #话题」那一行也能触发
· 修复：评论加载完后 UP 主信息卡片悬浮在页面上不走、快速下滑时又往上窜
· 修复：左栏评论上方那条「花生AI」站外推广横幅没有被屏蔽
· 首屏提速：弹幕发送控件提前约 2.5 秒出现；顶栏骨架栏补上搜索框与图标的灰占位；
  播放页的首屏轮询提前收工，不再和 B 站自己的渲染抢时间
· 「播放页优化」的说明文案改成「播放页焕新视觉效果，带来更沉浸播放体验」
```
