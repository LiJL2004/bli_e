# 1.2.0

> 打开速度与稳定性。

## 优化

- 三页白边统一成同一条：首页 / 搜索页 / 播放页不再各宽各的。
- 掐掉埋点上报、广告投放、播放器质量上报。
- 播放页首屏更快：布局改成「先读完再统一写」。
- 播放页首帧前先显示封面，黑屏时间缩短；悬停卡片时顺手预取这张封面。
- 首页大 banner 的图层图不再下载。
- 首页首屏不再「震」一下；骨架换真卡时淡入上浮，不再硬切。
- 顶栏导航（首页 / 动态 / 消息 / 收藏 / 历史）改为新标签页打开。

## 修复

- 夜间模式下的白卡、楼层卡白边、骨架扫光。
- 关掉「首页优化」后首页无限刷新。
- 页面合成的按键事件让全屏动画的监听抛错。
