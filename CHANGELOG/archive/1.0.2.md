# 1.0.2

> 1.0.1 已上架。本版新增「顶栏触发面板材质」（含右侧头像 / 消息 / 动态 / 收藏 / 历史的
> 悬停浮层）与首页按钮的悬停反馈；顶栏首屏不再出现 B 站的旧版顶栏（那层毛玻璃在首屏有额外开销），
> 字标改为内联、首屏不再读布局，并砍掉 DOM 监听里无用的部分。

## 新增

- **高级材质 → 顶栏触发面板材质（默认关闭）**：悬停顶栏「首页」弹出的频道面板，以及
  右侧头像 / 消息 / 动态 / 收藏 / 历史的悬停浮层，可以统一换成毛玻璃。
  开关默认关闭；打开后两个滑块的默认值 **38px / 61%** 与「搜索面板材质」一致
  （都是顶栏上弹下来的大面板，观感要统一），但各自独立存储，改一个不影响另一个。

## 新增 · 实验室

设置面板「个性设置」下面多了一个大菜单**实验室**：里面全是实验性开关，
后续版本可能改为默认开启，也可能长期留在这里，还可能被直接删掉 —— 这就是它存在的意义。
实验室开关**默认关闭**（它们改的是观感与手感，出问题会影响整站）。

- **全屏关闭动画**：从「动效增强」搬进实验室，仍然默认关闭。
- **夜间模式**：深色顶栏（`#1a1b1f` 渐变 + 白 8% 描边）、深色搜索框与面板卡片
  （`#202226`），强调色提到 `#6fb0ff` 保证深底上的对比度。只换顶栏 / 搜索框 /
  搜索面板 / 顶栏浮层这几块我们本来就在管的表面，不动 B 站正文（正文有自己的深色主题）。
- **浮动键胶囊化**：悬停时两枚圆键向左展开成带文字的胶囊（返回顶部 / 刷新）；
  点「返回顶部」时按钮边缘画一圈滚动进度，到顶自动收掉。
- **材质开关过渡**：材质开关一开原来是硬切，现在 `background-color` 走 200ms 过渡。
  `backdrop-filter` 不能补间：顶栏用一层常驻的玻璃叠层做 opacity 补间（只在打开这个
  开关时才创建那一层）；设置面板不借叠层 —— 面板自己就是从近不透明的 `#F7F7FA` 过渡到
  半透明白，模糊会随着底色变透被慢慢露出来。

## 变更

- **设置面板本身改版**（原「控制面板 beta」，已转正、不再有开关）：① 左侧分类加线性
  图标；② 数值从灰字改成可点的胶囊，点一下直接输入，不用拖滑块微调；③「恢复默认」与
  版本号抽成面板底部的固定操作条，不再挤在「个性设置」页末尾。

- **「面板卡片级联」挪进「动效增强」并改为默认开启**：打开面板时卡片按 18ms 递增淡入 +
  上移 4px；面板本身的开合动画一点不动，卡片这段特意做得更软（420ms 缓出 + 40ms 起步延迟），
  叠在缩放上不打架。

- **底部操作条左右互换**：开发版本号在左、「恢复默认」在右（原来是反过来的）。

- **「背景明暗」的显示值与编辑值统一**：胶囊上写的是「偏暗 6」这种偏离量，点开输入框
  原来却显示原始值 44。现在 `NumberParamDef` 多了一个可选的 `edit: { to, from }` 换算，
  输入框显示 6、提交时再换算回 44 —— 点开看到的就是胶囊上那个数字。

- **设置面板的开合动画回退到 1.0.1 原样**：上一版为了给玻璃做叠层补间，把面板自己的
  opacity 过渡去掉了，关闭时内容先「啪」地消失、只剩一层空玻璃再淡出，观感很怪。
  现在 `.panel` / `.panel.show` 与 1.0.1 **逐字节一致**，「材质开关过渡」只往同一个
  transition 列表里补三个颜色属性，不再插手开合；面板的玻璃也不再借叠层 —— 面板自己
  就是从近不透明的 `#F7F7FA` 过渡到半透明白，模糊会随着底色变透被慢慢露出来。

## 优化

- **播放页首屏不再出现 B 站旧版顶栏**：播放页在 Vue 接管前会先渲染一版旧顶栏，以前我们只把
  它的内容 `visibility:hidden`（留一条白条）。它带着一层毛玻璃 `::before`，整页首屏渲染期间
  一直在重算背景模糊 —— 8 轮 A/B（显示 vs 隐藏）中位数 3502 → 3070ms，但换成 v004/v005 直接
  对比只有 -18ms，**噪声很大，不能当作提速承诺**。现在**整块 `display:none`**，首屏这段由
  骨架栏（只画 logo、实色底、不做模糊）填住，新版顶栏一到一起退场。

- **字标改为 base64 内联**：顶栏 logo 原来用 `i0.hdslb.com` 上的 PNG 做 mask，首屏实测会请求两次
  （骨架栏 + 自绘 logo 各一次，其中一次花了 386ms），这段时间 logo 位置是空的。
  现在把这张 6.4KB 的图内联成 CSS 变量（只存一份，四条 mask 声明共用），首帧就有字标，
  也不再依赖 B 站 CDN。

- **首屏少读一次布局**：浮动键的滚动监听改成 `load` 之后再挂 —— 加载期间 B 站会打出大量
  scroll 事件，而每次同步都要读 `window.scrollY`，页面布局还没算完时读它会把待处理的
  布局强制 flush。实测我们首屏脚本时间：搜索页 100ms → **17ms**，首页 65ms → **≈15ms**。

- **悬停顶栏「首页」的反馈**：加上和「动态」同款的跳动动画（B 站只给普通导航项加了
  `jump`，首页被排除在外），旁边的下拉箭头同时做 180° 翻转；面板展开、鼠标移进面板后
  箭头保持朝上，不会弹回去。

- **首屏主线程**：`MutationObserver` 的回调在每个 DOM 批次上都会跑，首屏 B 站会打出
  成百上千批。两处无谓开销砍掉：① 顶栏出现后不再每批都 `querySelector('.bili-header')`；
  ② 预加载哨兵只有首页才有，没有哨兵时整段 `touchesFeed()`（要遍历 addedNodes 逐个
  `matches`，实测最坏占首屏脚本时间 60%）直接跳过。扩展自身在搜索页前 2s 的脚本时间
  约 150ms，优化前最坏会多出 180ms。骨架栏也不再挂 backdrop-filter（首屏它背后没有
  内容，模糊纯属白烧，实测能再省 ~200ms）。

## 修复

- **顶栏「首页」频道面板在毛玻璃下闪一下**（原版材质 → 高级材质）：
  淡入原来挂在外层 `#bili-elite-home-panel` 的 `opacity` 上，而外层一旦 `opacity < 1`
  就成了「背景根」，卡片上的 `backdrop-filter` 只能采到背景根内部（空的）—— 整段淡入
  期间玻璃**没有模糊**，到 `opacity` 归 1 那一帧才突然糊上。现在淡入挂到卡片自己身上
  （元素自己的 opacity 不影响自己的 backdrop-filter）。

- **右侧「消息 / 动态 / 收藏 / 历史」的悬停浮层在毛玻璃下闪烁**：B 站给这几个浮层用的是
  Vue 过渡类（`.v-popover_bottom-enter-from` 等，300ms），动的是**外层 `.v-popover`**
  的 `opacity` 0→1 和 `translateY(-5px→0)`。外层是 `.v-popover-content` 的祖先，祖先
  `opacity < 1` 就成了「背景根」，卡片的 `backdrop-filter` 只能采到背景根内部（空的）——
  整整 300ms 里玻璃一点模糊都没有，最后一帧才「啪」地糊上，所以看着比设置面板更闪。
  现在过渡期间把外层的 `opacity` 钉成 1（位移保留，滑动还在），淡入挪到卡片自己身上，
  曲线和时长跟 B 站那条 `all 0.3s` 对齐（都是默认 `ease`），滑动与显影同起同落。

- **数值胶囊点开输入框的过渡不够顺**：原来是「胶囊淡出 + 输入框从 1.1 缩到 1」的交叉淡入，
  中途能同时看到两个不同大小的盒子；输入框还自带白底和蓝描边，等于一块白底盖上来。
  现在改成**胶囊自己变成输入框**：底色浅蓝→白、补一圈蓝描边、文字 90ms 淡出，
  输入框换成透明底 + 无描边，只负责把文字错开 40ms 淡进来。两层几何完全重合，
  中间没有跳变。另外「全选」改成淡入过半（120ms）再执行，避免第一帧就跳出蓝底高亮；
  收尾时输入框先淡出、胶囊晚 60ms 再把文字淡回来，两段文字不会在同一帧叠成两层。
  顺带修了一个一直存在的几何 bug：输入框宽度取的是 `getBoundingClientRect()`，
  那个值会被面板的 `scale(var(--z))` 一起放大（默认 130% 缩放），写进 `style.width`
  之后输入框比胶囊宽出整整 30%（实测 80.6px vs 61.9px），往左探出去一截；
  改用 `offsetWidth`（布局像素）+ `box-sizing: border-box`，两边现在完全重合。

- **设置键点在圆盘边缘没反应**：`:active` 会把按钮缩到 88%，点在边缘时指针落到了缩小后
  的盒子外面，浏览器把 `click` 判给公共祖先 —— 表现正是「按下去有动画、松手没反应」。
  给按钮加一层透明的 `::after` 命中区（外扩 6px）：缩到 88% 后仍有 49px，稳稳盖住原来的
  44px 圆盘。实测：去掉命中区 0 次点击，加上后 1 次。

- **网页全屏时设置键盖在视频上面**：设置键 / 返回顶部 / 刷新三个宿主都是
  `position: fixed` + `z-index: 2147483647`，进网页全屏后会浮在播放器上方。
  新增 `videoLayer.ts`：盯 `<body>` 的 class（主站 `webscreen-fix`、直播站
  `player-full-win`），**进全屏把宿主整个藏起来**（`display: none`），退出全屏恢复。
  先试的是「把 z-index 压到 1000（按播放器 1002~1003 推的）」，实测按钮照旧浮在视频上面：
  网页全屏时 B 站给 body 加的是 `position: fixed`（z-index: auto），fixed 本身生成层叠
  上下文，播放器那套 `z-index: 100000` 被关在 body 这个 0 级上下文里；而我们的宿主是
  `<html>` 的直接子元素，只要 z-index 是正数就永远压在整棵 body 子树之上，压到 1 也一样。
  隐藏是唯一与层级无关的确定做法，视觉上也就是「被视频盖住」。只在 class 变化时算一次，不轮询。

- **首页「返回顶部」后点「刷新」，预加载不再自动加载**（下滑一下才恢复）：
  `IntersectionObserver` 只在**相交状态变化**时回调。「返回顶部」之后哨兵在视口下方
  （不相交），刷新把信息流换成一页新的之后哨兵跑到视口上方（仍然不相交）——
  状态没变，回调不触发，保活定时器一直不开；而 `syncPreloadAnchor()` 看到哨兵节点
  被复用（B 站刷新时常不换这个节点）就直接 return，观察器停在旧状态上。
  手动下滑会让几何连续变化、跨过一次阈值，所以「下滑后恢复」。
  现在信息流一有增删就打个脏标记，下一次 `sync()` 强制重建观察器 ——
  重建必然带一次初始回调，按当前几何重新判定，不再依赖「是否跨过阈值」。

- **鼠标悬停顶栏「首页」展开面板时没有动画**：面板原来是 `display: none ↔ block`，
  `display` 不可过渡，所以是「啪」地出现。改成 `visibility` + `opacity` +
  `translateY(-6px)` 的过渡（160ms 淡入 + 200ms 带回弹的位移），隐藏态
  `pointer-events: none`，避免透明面板挡住下面频道栏的点击。
