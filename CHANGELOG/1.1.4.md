# 1.1.4

> 播放页重排（默认开启），右下角那列浮钮可以收起来了。

## 新增

- 「播放页优化」：播放页从「居中 + 两侧大留白」改成满宽，标题 / 播放数据 / UP 主 / 操作栏按经典版顺序排到播放器下方（默认开启）。
- 操作浮钮收纳三条：自动隐藏、自动隐藏时保留操作键、半隐藏（默认全关）。
- 广告卡屏蔽默认生效。

## 修复

- 播放页打开后视频「停顿重播」一次；右栏跑到屏幕外；弹幕发送框过大、网页全屏回来后消失；打开时顶栏变成一条白；直播页画面不显示。
- 右栏推荐卡封面裁切 / 黑边；左栏不跟着钉住；宽屏与网页全屏被布局压坏。
- 番剧 / 纪录片等特殊播放页不再被改坏。
