# 1.2.5

> 本次更新重做了图片查看器，支持缩放、拖拽、旋转与左右滑动切图；同时把个人主页、搜索页的控件统一为与设置面板一致的样式。

## 新增

- 图片查看器重做：动态页、视频与动态的评论区、专栏等所有图片入口统一使用新的查看器，支持 50%~800% 缩放、放大后拖拽、左右旋转与一键复位，底部工具栏实时显示当前缩放比例。
- 查看器支持左右滑动切换图片，横向拖动超过一定距离即切换，滑到两端会回弹；左右箭头与键盘方向键同样触发切换动画。
- 图片打开时先用页面上的缩略图占位，再逐级换成更清晰的版本，不必对着空白等待。
- 个人主页的侧边分类、排序筛选与「播放全部」统一为与设置面板一致的胶囊样式，侧边按钮靠右排列、与右侧内容对齐。
- 搜索页顶部的分类标签改为文字标签页样式，底部指示条随切换平滑滑动。
- 播放页的播放器新增 12px 圆角，窗口态、宽屏与小窗生效，全屏保持直角。

## 优化

- 首页卡片的「已关注」标签改为「已订阅」式胶囊，带勾选图标，扫视时更容易与播放量那类标签区分。
- 设置面板与顶栏浮层的按钮统一为涟漪动效：波纹从实际点击位置铺满整个按钮，白色按钮按下去会明显泛蓝。
- 设置面板的开关控件缩小一档、点击范围一并放大；滑块轨道收细，蓝色进度条与圆点对齐。
- 动态页点击相册缩略图直接打开大图，不再经过中间那层「收起 / 查看大图 / 旋转」工具栏。
- 查看器内点击图片不再触发缩放或关闭，放大之后拖拽看图更省心。
- 搜索页的筛选按钮（排序 / 更多筛选 / 直播筛选）统一为与设置面板一致的胶囊圆角、配色与选中态。
- 播放页简介的「展开更多」按钮收窄到文字本身，整块简介卡片仍可点击展开。

## 修复

- 修复动态悬浮窗打开视频时，加载转圈期间视频已在后台起播、揭开后开头一小段被跳过的问题。
- 修复悬浮窗播放视频没有声音，以及静音状态会被误存成音量为 0 的问题。
- 修复播放器圆角四角残留黑边、以及圆角弧线上出现深色虚线的问题。
- 修复搜索页分类标签切换时新旧两条下划线叠在一起、首个标签贴边的问题。
- 修复动态页点击评论区会误弹出动态悬浮窗的问题。
- 修复在顶栏的历史 / 收藏浮层里点视频时，当前页也会同时弹出视频悬浮窗的问题。
