# 1.2.1

> 四处「看着就是没对齐」的毛病，外加评论预加载。

## 新增

- 「播放页优化 → 评论预加载」：视频起播、缓冲充足之后，先把评论第一页取回来。
- 设置面板新增「新版本改动」页。

## 优化

- 顶栏左右边距跟页面内容对齐（首页 / 搜索页 / 播放页 / 动态页）。
- 首页 / 搜索页的左右白边与播放页统一。
- 悬停预取修好命中问题，补上首屏空闲预取；两项合并成「播放页开启加速」并转正。
- 首页 / 搜索页的卡片大小默认值调到 350。

## 修复

- 搜索页右侧两根并排的滚动条。
- 非半顶栏时播放器与顶栏之间那条白缝。
- 大窗口下简介的「展开更多」是多余的。
- 数字藏品头像的 UP 主卡片上下空隙偏大。
- 卡片整体化后，播放页点白区会甩出新标签页。
- 首页推荐流偶发的整格空洞。
- 滚轮把搜索面板关掉。

## 变更

- 顶栏 logo 与「首页」改为在本页打开；顶栏搜索改为新标签页打开。
