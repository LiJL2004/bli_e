# 1.0.3

> 1.0.2 已上架。本版把设置面板的滑块换了一套画法、开关换成固定渐变并补上悬停反馈；
> 「顶栏材质」多了「顶栏渐变」与「背景明暗」，「面板卡片级联」移进实验室并改为默认关闭，
> 「顶栏触发面板材质」改为默认开启。

## 新增 · 高级材质

- **顶栏渐变（默认开启）**：顶栏玻璃从「实色一条」换成上实下透的竖向渐变 ——
  顶上仍是完整的模糊 + 白，越往下越透，最后和页面内容接上，底下那条硬边（发丝线 + 投影）
  一起收掉。依附于「顶栏材质」，材质关掉时这一行变灰、不可点。
- **顶栏背景明暗**：顶栏材质新增第三个滑块，直接调毛玻璃背后那层内容的亮度
  （`backdrop-filter` 里的 `brightness()`），50 为中性、往左压暗往右提亮，默认「适中」。
  顶栏这组默认值一起调成 **8px / 32% / 适中**，配合默认开启的「顶栏渐变」，
  装好就是「上白下透」的观感。

## 新增 · 开源地址

- 设置面板左侧新增「开源地址」分类（排在实验室下面，图标是 GitHub 的 octocat）：
  一页两行 —— **开源地址** 与 **开源许可证**，各带一个「前往」按钮，分别打开
  `https://github.com/LiJL2004/bli_e` 与 `https://github.com/LiJL2004/bli_e/blob/main/LICENSE`。
  链接是普通的 `<a target="_blank">`，不走 `window.open`（内容脚本里容易被弹窗拦截）。

## 变更

- **设置面板滑块换画法**：轨道从 6px 加粗到 18px 的胶囊，滑块从 18px 缩到 14px 并
  **落进轨道内部**（上下各留 2px）；悬停 / 拖动的缩放与光晕动效原样保留。
  蓝色填充改成**从左到右由浅到深**（`#B3D6FF` → `#2A78FF`），渐变铺满整条轨道，
  填充只揭开走到的那一段 —— 滑块在中间，看到的就只是整条渐变的前 50%，
  不会把完整渐变压缩进半截。
  填充宽度按「滑块中心 + 半个滑块 + 2px 留边」算，任何取值下滑块都被完整包在蓝条里，
  拉到 0 时蓝条正好是一个比滑块大一圈的圆。
- **开关去掉流动高光**：原来那条来回扫的白光删掉了，换成固定的浅→深蓝
  （`#4E96FF` → `#2A78FF`，幅度比之前小一半），安静下来。开关和滑块现在共用同一套
  灰底、同一个白色拇指（同款径向渐变 + 蓝色描边 + 投影）、同一个 3px 留边比例
  （滑块 14/18、开关 20/26），按住时两者都会泛一层同样的淡蓝光晕。
- **开关也有悬停反馈**：鼠标移到开关上，拇指涨起来、光晕散开再自己收回去 ——
  整段只播一次（0.78s，幅度 1.09），停在上面不会一直保持放大态，移开再移回来才会重播。
- **高级材质一页一行**：这一页每项都是「开关 + 三条滑块」，原来两两并排会把滑块压得很窄，
  数值也顶不到右边。现在每张卡都整行铺满，滑块拉到底、数值贴右边。
- **设置面板尺寸改为按视口比例**：面板基准占视口的 47.4% × 62%，再乘「设置面板缩放」——
  换多大的窗口，面板占屏幕的比例都一样（默认 100% 时恒为 56.9% × 74.4%，1440×900 下
  是 819×670）。以前是 1000×660 的固定像素，窗口一大占比就变小。140% 用 96vw / 92vh
  兜底，不会贴边。
- **首页内容区布局并进「首页优化」**：B 站首页的左右留白是写死的两档（< 1680 是 60px、
  ≥ 1680 是 140px），内容区再封顶 2260px、栅格固定 5 列 —— 于是窗口越宽白边占比越大
  （1920 是 7.3%、2560 是 11.3%），右下角那颗 ⚙ 飘在一大片空地上。现在「首页优化」
  一开就把留白换成「刚好容得下浮动键」的 88px（宽屏按 4.6vw 缓涨，上限 132px），
  内容区不再封顶、栅格改 auto-fill；同一张卡里新增「卡片大小」滑块（220–380px，
  默认 320px），它设的是卡片最小宽度，窗口越宽多排一列，而不是把卡片拉胖。
- **设置面板右侧恒定留出滚动条的位置**：以前某一页内容不够长、没有滚动条时，
  内容会比有滚动条的页面宽 8px，切分类时整页横向抖一下；现在固定预留。
- **「设置面板缩放」的刻度整体重标定**：原来 100% 是 1.0 倍基准、120% 才 1.2 倍，
  现在把 1.2 倍定为「100%」，默认值也从 130% 改成 **100%**，范围仍是 80–140%。
  老版本存下的数值会按新刻度换算一次（旧 130 → 新 110），面板不会突然撑满屏幕。
- **高级材质文案统一**：每张卡的开关统一叫「材质」，滑块统一叫「渐变 / 模糊强度 /
  遮罩强度 / 背景明暗」，不再带「顶栏 / 搜索框 / 评论区图片…」前缀；
  每张卡上方补一行灰色小字（评论区图片背景 / 顶栏 / 搜索框 / 搜索面板 / 顶栏触发面板 /
  设置面板）说明这张卡管的是哪一块。
- **顶栏触发面板材质改为默认开启**：悬停顶栏「首页」的频道面板，以及右侧头像 / 消息 /
  动态 / 收藏 / 历史的悬停浮层，装好就是毛玻璃。已经装过的用户沿用自己存的值，
  想跟着改的话点一下「恢复默认设置」。
