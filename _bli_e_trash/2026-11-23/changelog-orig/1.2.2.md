# 1.2.2

> 1.2.1（2026-11-06 上架）之后累积的一批改动，正式发版为 1.2.2。内容上分三块：
> **播放页**（评论预加载、右栏点白区不再甩新标签页、右栏视频恢复即时切换、实验室的
> 「播放页开启加速」转正到界面优化并默认开启）、**首页**（推荐流偶发的整格空白、
> 广告卡认骨架）、**面板与顶栏**（新增「新版本改动」页、首页 / 搜索页默认卡片 350px、
> 顶栏左侧悬停衬底、滚轮不再关掉搜索面板）。

本版没有引入新架构，全部是 1.2.1 开发期（v006 ~ v029）的记录，逐条细节、量测数据与
「为什么这么改」都在 **`CHANGELOG/1.2.1.md`** —— 那份日志里的 v006 及之后的每一节都属于
这次发版的内容，这里只做索引，不再复制一遍。

## 用户可见的改动（= 设置面板「新版本改动」页的内容）

见 `src/contentScripts/modules/whatsNew.ts`。**两份要同步改**：那份是给用户看的
（只讲能体验到什么），这份是给开发看的。

## 相对 1.2.1 的功能面变化

| 功能 | 变化 |
| --- | --- |
| 评论预加载 | 新增（`videoCommentPreload`，挂在「播放页优化」卡里，默认开） |
| 播放页开启加速 | 从「实验室」转正到「界面优化」，默认开（`playBoost`） |
| 新版本改动 | 设置面板新增的一页（文案在 `whatsNew.ts`，样式在 `panel.css` §24） |
| 首页 / 搜索页卡片大小 | 默认值 340 → 350（CSS fallback 同步） |
| 实验室 | 只剩「浮动键胶囊化」一项 |
