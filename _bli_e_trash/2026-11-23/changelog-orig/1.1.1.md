# 1.1.1

> 小版本：动效与圆角统一收进 token、四处性能收口；新增「减少动态效果」适配、当前页
> 指示、材质实时预览，夜间模式与面板级联转正；卡片入场不再硬切、频道面板收起更顺；
> 顶栏导航控件悬停时多一层蓝色光晕；卡片右下角「⋮」的悬停菜单接上「高级材质」，
> 并把「顶栏触发面板」改名为「触发面板」。

## 新增 · 卡片「⋮」菜单适配高级材质

- **现象**：开着高级材质时，悬停卡片右下角「⋮」弹出的菜单还是一整块不透明白卡片，
  和周围所有毛玻璃浮层格格不入。
- **结构**（实测 2026-10-23 —— 它挂在 `body` 下，不在卡片里）：
  `.vui_popover` → `.vui_popover-content.bili-video-card__info--popover` →
  `.bili-video-card__info--no-interest-panel`。两层白底叠着，只透明化外面那层没用。
- **处理**：两层一起透明化（直播卡的 `.bili-live-card__info--popover` 同一套结构，一并处理），
  描边 / 投影换成和频道面板一致的写法；条目悬停底从 `--graph_bg_regular_float` 换成半透明灰。
  模糊 / 遮罩直接沿用「触发面板」那两个变量 —— 高级材质里不给它单独加滑块。
- **入场淡入也要「挪一层」**（和右侧浮层那个坑一模一样）：`.vui_popover` 自带
  `transition: opacity .3s`，Vue 过渡类把**外层**的 opacity 从 0 拉到 1；祖先 opacity<1
  就是背景根，这 300ms 里玻璃一点模糊都没有，最后一帧才「啪」地糊上。处理是把外层
  opacity 钉成 1（位移在 transform 上，不动它），淡入挪到 `.vui_popover-content` 自己身上。
  只挑「装着卡片菜单的 popover」—— 全站 tooltip 也是这个类，不能一起改。
- 夜间模式下玻璃层换深色（`#202226` / `brightness(0.55)`），与其余几块材质一致。

## 新增 · 顶栏控件的悬停光晕

- **需求**：顶栏控件悬停时原来只有「文字变蓝 + 图标跳动」，在毛玻璃底上存在感偏弱。
  现在每个控件悬停时再多一层品牌蓝的柔光，把「可点」这件事说清楚。
- **范围**：自绘 logo、「首页 ∨」「动态」，以及右侧消息 / 动态 / 收藏 / 历史（图标 + 文字）。
  **不加光晕的三处**：搜索框（自带一整块材质，再加光晕会显得脏）、头像（圆形，加光晕像
  「选中」）、投稿（实心粉色胶囊，外面套蓝边更不像它自己）—— 后两个是看过实际效果后
  按用户要求去掉的。
- **做法**：不铺任何背景块，只加 `drop-shadow` —— 光晕贴着字形和图标的轮廓走，
  不会在毛玻璃上多出一块方底。两层（4px 贴身 + 12px 外扩），悬停 0.22s 淡入。
- **一个必须踩准的坑**：光晕只能挂在 trigger 那一层。父层 `.left-entry__item` /
  `.right-entry__item` 其实是 `.v-popover-wrap`，右侧那些悬停浮层就装在它里面；
  `filter` 会建立背景根，浮层的毛玻璃会当场失效（和 1.0.4 右侧浮层那条同源）。
  实测把光晕挂在 trigger 上、浮层打开时，浮层的 `backdrop-filter` 仍然有效。
- **logo 的坑**：字标是「纯色背景 + mask」，`filter` 在 `mask` 之前求值 —— 把光晕挂在
  `.bili-elite-logo__mark` 上等于给一块 76×34 的实心方块做投影，再被 mask 一起裁掉，
  屏幕上什么也看不见。必须挂在 `<a>` 上。
- 颜色抽成 `--bili-glow`（rgb 三元组）：白天 `#00aeec`，夜间（实验室 → 夜间模式）
  换成强调色 `#6fb0ff`，和夜间顶栏 hover 文字同色。

## 变更 · 动效统一收口（token）

- 全站动效时长原来有九种（0.16 / 0.17 / 0.18 / 0.2 / 0.22 / 0.26 / 0.28 / 0.3 / 0.32s），
  散在五个样式表里，改一个动效只能凭手感挑一个最像的数。现在收成三档 + 两条曲线，
  定义在 `motionTokens.css` 的 `:root` 上，由 `injectMotionTokens()` 在入口最先注入：
  - 快 160ms：悬停变色、光晕、图标微动；
  - 常规 220ms：下拉面板、浮层、卡片进出；
  - 慢 320ms：收起、材质切换、较大位移；
  - `--bili-ease` 标准曲线（进出对称）、`--bili-ease-spring` 回弹曲线（只给弹出的方向）。
- 已覆盖 `topbar.css` / `floatingButtons.css` / `lab.css` / `dynamic.css`。
- **设置面板的开合动画不动**：那条 transition 列表与 v1.0.1 逐字节对齐，套上 token 以后
  谁调 token 都会连带改掉面板手感 —— 所以 `panel.css` 保留原值，等面板单独改版时再收。
- 仍写死毫秒的只剩三类，都有理由：对齐 B 站自身时长的（顶栏 jump 0.3s、浮层淡入 0.3s）、
  一次性特殊动画（刷新键旋转 0.6s、面板级联 0.42s）、微交互（clip-path 0.06s）。

## 新增 · 卡片入场淡入

- **现象**：骨架格被真卡顶掉的那一帧是硬切，滚动加载时一屏十几张卡同时「啪」地出现。
- **做法**：真卡插进来时由 `markNewCards()` 打上 `bili-elite-card-in`，CSS 里跑一次
  160ms 的 `opacity 0→1`（`backwards` 填充，动画结束把样式交还给元素本身）。
- **为什么不是真的「骨架淡出」**：骨架是 B 站自己的节点，真卡一到位就被同步移除；想让它
  淡出只能克隆一份做叠层，那要多一次布局、首帧还大概率闪一下（克隆出来时尺寸还没跟上）。
  所以淡入做在真卡自己身上 —— 骨架消失的同一帧开始淡入，观感上就是一次交叉淡入。
- 只标「新插进来、且不含骨架」的卡：首屏 SSR 那批（页面一出来就在，淡入反而像闪）和
  脚本自己补的占位格都不标。
- 成本：判定挂在已有的 MutationObserver 回调里，第一行先看 `addedNodes` 是否为空
  （绝大多数批次只是改属性 / 文本），再看最近的容器是不是推荐栅格 / 搜索结果列表。

## 修复 · 频道面板收起时被「切掉」

- **现象**：悬停「首页」的频道面板收起来有点生硬，像是凭空消失。
- **原因**：`visibility` 的延迟写的是 0.16s，而位移和卡片淡出都是 0.2s —— 面板在动画走到
  80% 时就被切掉了，最后那段位移根本没播出来。
- **处理**：收起的位移换成常规档（220ms + 标准曲线，不弹），卡片淡出同步 220ms，
  `visibility` 延迟也对齐 220ms；展开仍走回弹曲线 + 160ms 淡入（快一点更精神）。

## 新增 · 尊重系统的「减少动态效果」

- **是什么**：macOS / iOS「减弱动态效果」、Windows「关闭动画」打开后，系统会给页面一个
  `prefers-reduced-motion: reduce`。对前庭功能敏感、晕动症、偏头痛的用户来说，大面积位移
  和缩放不是快慢问题，是会引发不适 —— 而这正是我们最拿手的几段动效（全屏开合、图片
  FLIP、面板位移）。
- **处理**：`designTokens.css` 里一段全局媒体查询，把**位移 / 缩放 / 旋转**去掉，只留颜色
  与透明度的过渡：
  - 顶栏导航的跳动直接 `animation: none`；
  - 频道面板、搜索面板的 `transform` 归零（淡入淡出保留）；
  - 浮动键胶囊化的宽度伸缩不做补间（这条写在 `floatingButtons.css` —— 它在 Shadow DOM 里，
    页面级样式够不着）；
  - 图片 FLIP 与网页全屏动画在 JS 里判断 `prefersReducedMotion()` 后直接跳过。
- **不动的**：设置面板的开合动画（与 v1.0.1 逐字节对齐，按约定不改），以及所有颜色类过渡。

## 新增 · 当前页导航指示

- 顶栏两个导航项原来只有悬停态，看不出自己在哪一页。现在首页 / 动态页各在文字下方亮一条
  2px 短横（颜色取 `--bili-glow`，与悬停光晕同色）。其它页面不亮 —— 视频页 / 搜索页本来
  就不属于这两个入口。
- 判断只看 `hostname + pathname`（`syncNavMark()`），不去猜「B 站认为哪个 nav 项被选中」
  —— 它自己都没做这件事。

## 新增 · 材质实时预览

- 每个材质的第一行（模糊强度那行）左边多一个 24×24 的小方块：底下一张彩色渐变，上面盖
  一层跟着滑块走的毛玻璃，拖滑块就能看到当前模糊 / 遮罩到什么程度，不用来回开关面板盲调。
- 底层和材质层是**同一个 24×24 圆角矩形**（都 `inset: 0`、都继承圆角），叠在一起严丝合缝；
  底色用四象限实色而不是柔和渐变 —— 渐变在四角会淡出，整块看着像个没边界的色团。
- 方块里的模糊按 0.15 缩放显示 —— 24px 的窗口照搬 20–40px 的真实模糊会「整块糊平」，
  三个档位看着一模一样；缩放后相对强弱仍在（0 依然清晰、60 最糊）。

## 性能 · 四处收口

- **MutationObserver 收窄**：原来 `observe(document.documentElement, {subtree: true})` 等于
  监听整页，评论区、播放器、右栏的每次变动都会把回调叫起来。现在只观察「顶栏 + 信息流栅格」
  两个根。**收窄的时机是「真顶栏的导航项就位」而不是「.bili-header 出现」**：播放页会先
  渲染一版 `.bili-header.fixed-header`（被我们整块隐藏），按 `.bili-header` 去挂会盯上一个
  马上被替换的节点，真顶栏插进来后就再也收不到回调 —— 顶栏会永远停在半成品状态。
  导航项就位前继续观察整页（代价与以前相同），就位后才收窄；节点被整块换掉时由
  `sync()` 开头的 `observeRoots()` 重挂。
- **设置面板样式懒注入**：`panel.css` 近千行、7 处 `backdrop-filter`，原来 DOMContentLoaded
  就整块塞进 Shadow DOM。现在首屏只注入 `panelButton.css`（⚙ 按钮那几十行），第一次点 ⚙
  才注入面板样式。注入前 `.panel` / `.confirm-mask` 靠一条 `display:none` 藏住，
  注入后由 panel.css 的显式 `display` 覆盖 —— 实测注入前后 `display` 从 none 变 flex、
  按钮样式全程在线。
- **悬停光晕改用 `text-shadow`**：文字部分不再走 `filter: drop-shadow`（每次悬停都新建 /
  销毁一个合成层），只有 SVG 图标和「首页」那个遮罩箭头保留 `filter`。
- **启动顺序**：图片查看器、图片材质、浮动键三块挪到 `requestIdleCallback`
  （带 1s 兜底），首屏只留 ⚙ 按钮、全屏动画和一段 CSS。
- **`contain` 这次没加**：本想给面板 / 卡片菜单加 `contain: layout paint` 收窄重绘，实测
  这三块都是「悬停 / 打开时才会画」的表面，滚动期间本来就不重绘，收益接近零；而给信息流
  卡片加 `contain` 会改变绝对定位后代的包含块（B 站卡片里有角标、浮钮），风险大于收益。
  按「不行就放弃」处理，没有加。

## 修复 · 两处视觉瑕疵

### 「刚刚在其他设备上播放」卡片上悬空一个白色菱形

- **现象**：开着高级材质，悬停「历史」弹出跨设备续播卡片，卡片上沿悬着一个白色菱形 ——
  卡片本身是毛玻璃，菱形却是实心的白块。
- **原因**：B 站用 `.continuous-history-card::after` 画了个 15×15、`rotate(45deg)` 的方块
  （`top: -8px`，`left: 50%` 再右移 50px），底色是 `--bg1_float`（亮色下纯白）。白卡片上
  看不出来；§7.2 把 `.v-popover-content` 换成毛玻璃、`> *` 透明化之后，卡片透明了、
  这块还是白的，就成了悬空的菱形。
- **处理**：直接去掉这个箭头（`topbar.css` §7.7）。浮层位置本来就贴着「历史」，箭头没有
  信息量；要保留它就得单独给它配一层模糊，接缝反而比去掉更显眼。

### 当前页指示条长度对不上、滚动一屏后消失

- **现象**：首页「首页 ∨」下方那条 2px 蓝色短横比文字短一截、还整体偏右；往下滚一屏，
  短横直接不见了。
- **原因一（长度）**：短横原来写死 `width: 16px` + `left: 50%` 居中在 `<a>` 上。而这个
  `<a>` 是整个 64px 高的可点区域，宽 43px（文字 28 + 自绘箭头 10 + 间距 5）—— 居中之后
  短横既短于文字、又偏到箭头那一侧。
- **原因二（消失）**：往下滚之后 B 站把「首页」那一项整个换成收起态组件，类名从
  `.home-page-entry` 变成 `.home-page-panel-entry`。选择器只认前者，短横就没了。
- **处理**：两个类都认；宽度改成 `left: 0; right: 0` 撑满整块可点区 —— 短横现在从「首」
  的左边缘一直盖到下拉箭头的右边缘（43px = 文字 28 + 箭头 10 + 间距 5），换字号也不会错位。
