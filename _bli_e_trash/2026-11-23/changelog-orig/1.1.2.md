# 1.1.2

> 小版本：新增设置分组「快捷功能」，里面是**功能轮盘** —— 按住 Tab 在屏幕中央展开圆盘、
> 移动鼠标选一格、松开直接过去。八个方向固定、位置与参考图一致，呼出键可改绑，
> 每一格装什么都能在「轮盘编辑器」里换。目前只在首页与动态页生效。

## 新增 · 快捷功能 · 功能轮盘

- **形态**：按住呼出键（默认 **Tab**）→ 屏幕正中展开一个圆盘 → 移动鼠标把指针指向某一格 →
  **松开呼出键**就跳过去。
- **八个方向是固定的**（`quickWheelLayout.ts`）：顶部 0° → 右上 45° → 右 90° → 右下 135° →
  底部 180° → 左下 225° → 左 270° → 左上 315°，每格 45°，与参考图完全一致。
  - 为什么不是「按项目数均分」：需求要求**最上方是首页、最下方是动态**，这两条同时成立的
    前提是方向数为偶数 —— 7 等分（51.43°）时正下方根本没有槽位，动态只能歪在 154.3°。
  - 固定之后**槽位是「位置」而不是「列表项」**：卸下只会把某一格清空，位置本身不会消失，
    圆盘也不会「少一项就缩一圈重排」。
  - 功能池八项，默认正好装满八格（左右各三）；卸下某一格之后才会出现空位，空槽画成虚线占位圈。

- **中心空档 = 取消**：指针停在圆盘正中时方向没有意义，这时候不替用户选任何东西；
  一次都没选过就松手，等于什么都没发生（防误触）。指到空槽上也一样（不选中）。
- **已经在目标页上时只收起、不跳转**（用户明确要求）：比如人在首页、轮盘选「首页」，
  松手后什么也不会发生，圆盘中心那行提示会提前写成「已在当前页 · 松开收起」。
- **首页 / 动态页 / 视频页生效**（`quickWheel.ts` 的 `pageAllowed`，视频页含 `/video/BVxxx`
  与 `/bangumi/play/xxx`）。这三类都是「内容页」，Tab 的默认行为是切焦点，按住才接管、
  松开就还回去，冲突可接受；搜索页 / 个人空间 / 消息中心是表单和列表操作的重灾区，先不接。
  以后要扩页面只改这一个函数。

- **不抢键盘的三种情况**：焦点在输入框 / textarea / contenteditable 里（评论区、搜索框、
  动态发布框）；设置面板开着（面板里 Tab 要能正常切焦点）；按着 Ctrl / ⌘ / Alt / Shift。
- **键盘党**：轮盘开着时数字键 1–8 直接选第 N 格（空槽跳过），Esc 放弃，切标签页 / 窗口
  失焦自动收起。
- **不占首屏**：DOM 等到第一次呼出才建。平时只挂一个 keydown 监听；鼠标 / 滚轮那几个监听
  **只在展开期间挂**（`bindStage` / `unbindStage`）—— 非被动的 `wheel` 监听会让整页滚动
  走不了浏览器的快路径，首页要滚一整天，不能常驻。
- **层级 / 网页全屏**：与设置键同级（2147483647，靠 DOM 顺序压住 ⚙），并且和浮动键一样
  由 `videoLayer.ts` 管 —— 进网页全屏直接 `display:none`，别压在视频上。

### 视觉：跟设置面板同一套材质，不用游戏那套深色描金

- 环带是极浅的蓝灰（`rgba(240,245,252,.86)` + 背景模糊）、中心留白 —— 两者必须能分开，
  最初整块都是半透明白，在浅色页面上就是一团白，看不出是「轮盘」。颜色取自面板卡片，
  所以它和设置面板看起来是同一块材质。
- 图标是白底圆形胶囊 + 品牌蓝线性图标；选中那一格：扇区铺一层 13% 蓝、图标变成蓝色实心圆、
  整颗放大 8%。与面板里「选中态用蓝」是同一套语言。
- 空槽：虚线占位圈，不加图标 —— 说明「这个方向还在，只是没装东西」。
- 夜间模式（实验室 → 夜间模式）下整块换成 `#16171a` / `#202226` / 强调色 `#6fb0ff`，
  与 night.css 对齐；`is-night` 类在每次展开时按 `<html>` 上的 `bili-elite-night` 重新算。
- 尊重系统「减少动态效果」：只保留淡入淡出，去掉圆盘缩放。这段写在 `quickWheel.css` 里
  —— 页面级的 `designTokens.css` 进不了 Shadow DOM。

## 新增 · 轮盘编辑器

- 位置：设置面板 → **快捷功能 → 轮盘项目 → 编辑**。打开的是比确认弹窗更大的卡片：
  左边圆盘预览、右边「功能入口」格子，右下角「卸下」。
- **两侧的选中互不联动**（这一版的重点）：左边选的是**位置**，右边选的是**功能**。
  点左边某一格时，右边**不会**跟着亮 —— 右侧只保留「已装入」的序号徽章与浅蓝描边，
  那是状态标记，不是选中。
- 编辑规则：
  - **只选左侧某格**：该格高亮，中心显示它的名字与说明；再点同一格取消选中。
  - **选中左侧某格 → 点右侧功能**：用这个功能**替换**那一格。如果它已经在别的格，
    两边**交换**（功能池固定，不能凭空丢一个）；之后两侧选中都清空。
  - **先点右侧功能 → 再点左侧某格**：同样把功能换到那一格，两边清空（用户要求的「反过来也行」）。
  - **只选右侧某功能**：它自己高亮（描边 + 蓝底 + 蓝字），提示变成「再点一个圆盘位置，
    就把它换过去」；再点同一格取消选中。
  - **卸下**：清空左侧选中的那一格，并且**那一格不再被选中**。功能没有丢，它回到右侧列表里，
    随时能再装。
- 「卸下」按钮**是品牌蓝**（不是红色）：它只是把功能从轮盘上摘下来，不是不可逆的删除。
  没有选中「装着东西的格」时按钮是禁用的（压灰、不给点）。
- 预览和页面上的轮盘**共用 `quickWheelLayout.ts`**（扇区路径、分隔线、图标偏移、指针 → 槽位），
  所以预览里看到的排布就是实际展开时的排布。
- **为什么编辑器是 `.panel` 的兄弟节点**：面板本身 `overflow:hidden`，塞进去会被裁掉。
  代价是它拿不到 `.panel.is-night / .is-glass`，所以这两个类由 `syncUI` 单独切一份。
- **编辑器里的点击必须 `stopPropagation`**：设置面板有一条「点面板外面就关面板」的
  document 监听，不拦住的话编辑到一半点一下格子，整块面板就没了。
- 夜间 / 毛玻璃：跟着「夜间模式」与「设置面板材质」走，配色与 §21 的夜间面板一致。

## 新增 · 呼出键可改绑

- 快捷功能页第二行是呼出按键，点一下胶囊进入「请按键…」状态（白底 + 蓝描边，和数值胶囊的
  就地编辑态同一套观感），按任意键即改绑，Esc 取消。
- 存的是 **`KeyboardEvent.code`（物理键位）**而不是 `key`：换输入法、开着大写、换键盘布局
  都不会让绑定失效。面板上显示的是它的中文名（`keyLabel`），查不到就退回 code 本身。
- 只按修饰键（Shift / Ctrl / Alt / ⌘）不算数 —— 单按它们本来就没意义，还容易误触。
- **一个必须处理的顺序问题**：轮盘监听在 `window` 的**捕获**阶段，比面板挂在 `document`
  捕获阶段的按键监听更早跑。不处理的话，用户在面板里按 Tab 想改绑，轮盘会同时弹出来、
  还把这次按键吃掉，绑定框永远等不到。所以 `quickWheelConfig` 里留了一个
  `setWheelKeyCapturing` 标志，面板进入绑定态时置位，轮盘的 keydown 第一行就看它。

## 变更 · 设置面板多一组「快捷功能」

- 位置在**界面优化**与**个性设置**之间（`features.ts` 里 FEATURES 的顺序就是分类顺序）。
- 这一页不走通用渲染：除了开关，还有「呼出按键」「轮盘项目」两行自定义控件，所以整页单独
  拼（开关那一行仍复用 `toggleRowHtml`，接线照旧走 `input[data-key]`，不用特殊处理）。
- 左侧导航多一个轮盘图标（外圈 + 内点 + 四向刻度）。
- **「恢复默认设置」会把轮盘一起复位**：呼出键回 Tab、八个槽位回默认排布。
  `quickWheelConfig` 不是数值 store，所以单独加了 `resetWheelConfig()`，并且在
  `restoreDefaults()` 里补了 `setListening(false)` —— 否则按键胶囊会停在「请按键…」。
- 开关默认**开**：这是这一版的主功能，装上就该能用。不想要的人关掉即可。

  63px（46 图标 + 3 间距 + 14 字高）：空槽只放图标、容器一样高，不会矮一截。

## 新增 · 「轮盘背景」材质

- 「高级材质」里多了一张卡：**轮盘背景**（开关 + 模糊强度 + 遮罩强度，默认 24px / 61%）。
  想更透、更实自己拖，关掉就是一块实色圆盘 —— 在视频页那种深色画面上，实色反而更干净。

- 参数走 `wheelGlassConfig.ts`（独立 store，key `bili-elite-wheelglass-params`），
  写进 `:root` 的 `--bili-wheel-blur` / `--bili-wheel-tint`。轮盘在 Shadow DOM 里，
  而自定义属性会穿过 shadow 边界继承下来，所以不用给轮盘塞第二份参数。
- 面板里那张卡复用通用材质卡：24×24 实时预览、滑块、数值胶囊、「恢复默认」都会自动生效。

## 变更 · 视觉与动效

- 圆盘底色拆成两种：材质开着是半透明蓝灰 + 背景模糊（`.stage.is-glass .disc`），
  关着是实色 `#EFF4FB`。夜间各有一套（`#1A1B1F` / 深色半透明）。
- 图标胶囊 46px、图标 24px，比原来大一圈；选中时图标上浮 2px + 放大 6%、换成蓝色渐变，
  名字同步转蓝加粗 —— 中心文字、扇区高亮、图标三者一起变，眼睛不用来回找。
- **展开时八格按顺时针逐个弹出**（`chip-in`：260ms + 每格 14ms 延迟，`--i` 由 JS 写）。
  圆盘本身还是 220ms 的缩放，两者叠起来总时长约 360ms，收尾是软着陆，不抢戏。
- 名字加了一层极淡的白影（`text-shadow`）：圆盘半透明，浅色页面上 11px 小字容易糊。
- 「减少动态效果」下：圆盘不缩放、格子不弹出、图标不位移，只留颜色过渡。

## 修复 · 收回时「卡一下」+ 第一次呼出掉帧


两条都是**先量再改**，改之前各拍了一段逐帧数据（`requestAnimationFrame` 记录每帧间隔 +
关键元素的 `transform` / `opacity` 计算值）。

**收回「卡」不是掉帧，是编排错了。** 帧间隔全程稳定 7ms，一帧没掉。问题出在时间线上：

- 轮盘本体 200ms 只从 1 缩到 **0.94**（肉眼几乎看不出），而且 `opacity` 一直是 1；
- 八格图标在 t=215ms 已经全部淡出，轮盘却还原样留在屏幕上；
- 之后一直空转到 t=333ms 才 `visibility:hidden` 瞬间消失。

也就是说：**120ms 里画面完全不动，然后「啪」一下没了** —— 观感就是卡住。现在改成
缩放和淡出同时进行、所有元素在同一条时间线收尾（最长的一条 `.scrim` 200ms 就是整段长度），
轮盘缩到 0.9 的同时透明度归零，不再有静止的尾巴。

**第一次呼出掉帧**（63ms / 28ms / 55ms，第二、三次都是 7ms 一帧）：
全屏 `backdrop-filter` 的 shader 要到第一次真正上屏时才编译，加上 19px 模糊的首帧光栅化。
现在页面空闲时先 `build()` + `render()` 把 DOM 建好（只 `build()` 不够 —— 花瓣和图标是
`render()` 填进去的，不填一遍预热的只是个空盘子），再给遮罩 1% 不透明度跑两帧，
把 shader 编译和首次光栅化挪到用户按键之前。1% × 16% 暗色 = 0.16%，肉眼看不见。
改完三次呼出都是 7ms 一帧、零长帧。

## 变更 · 轮盘材质固定 + 呼出/收回动画重做


- **「轮盘背景」只负责背景了**：它现在只管轮盘外那层全屏虚化（模糊 + 背景暗度，默认
  19px / 16%）。之前那两个滑块同时管着圆盘和中心圆，结果是「遮罩一拉高，圆盘变成一块
  白片、字也糊」—— 材质不该有「调坏」的可能。
- **轮盘本体换成一套写死的材质**：八片花瓣是白色径向渐变（内 0.8 → 外 0.66 → 边缘 0，
  选中换品牌蓝）；中心圆是一张白色渐变卡片（`linear-gradient(180deg, .95 → .85)`）+
  发丝描边 + 投影。白度是挑出来的：深色页面上它是浅灰卡、浅色页面上是白卡，两种情况下
  深色文字都有足够对比度 —— 名字永远读得清。夜间换成深色卡 + 浅色字。
- **中心圆里不许出现 `backdrop-filter`**：整块 `.wheel` 进出场时在缩放 + 淡入淡出，
  祖先的 opacity / transform 每帧变化都会让内部那层重新采样背景；而 0.86 白本来就没什么
  可透的，去掉模糊肉眼几乎看不出差别（顶上补一道竖向高光就够了）。
- **呼出动画（约 290ms）**：轮盘 260ms 缓出 + 轻微过冲（0.9 → 1）并同时淡入，
  中心圆晚 30ms、用 280ms 落定（层次感），八格顺时针逐个弹出（240ms + 每格 8ms）。
- **收回动画（约 200ms）**：反着来 —— 轮盘 200ms **缓入**（越走越快）连缩带淡一起结束，
  八格反向错开淡出（最后弹出来的那格先走，120ms + 每格 4ms），
  `visibility` 延迟 210ms 才真正隐藏。这是 iOS 那套「进场减速、退场加速」的手感。
- 「减少动态效果」下全部退化为淡入淡出（中心圆的居中位移保留，缩放去掉）。


## 变更 · 轮盘重做：大中心圆 + 八片分开的功能区


照着参考图把结构改了一遍 —— 之前是「一整块半透明圆盘 + 八根分隔线 + 一个 0.37 半径的
小中心圆」，说白了就是一块饼上画了几道线，所以怎么看都像「贴上去的板」。

- **中心圆放大到外径的 0.44**（半径 92 / 外径 210）。之前 0.37 的比例环带太宽、中心局促，
  两行字挤在一起。
- **八个功能区是真的断开**：每片单侧让 2.2°（合起来 4.4°，外缘处约 16px），
  与中心圆之间再留 12px 环缝。「一格一格分开」是靠**留白**做的，不是画分隔线 ——
  参考图里那八块本来就是断开的。
- **每片到外缘渐隐**：填充换成 SVG 的 `radialGradient`（`gradientUnits="userSpaceOnUse"`，
  圆心 = 轮盘中心），内段 0.8 白、0.86 处 0.66、0.96 处 0.16、最后一圈归零。
  渐隐**必须提前**：上一版到 0.9 还有 0.64，结果八片一直到外缘都是实心的，缝隙就是八条
  硬邦邦的深色「辐条」；现在花瓣的外缘和缝隙一起融进背景。选中态同理，换品牌蓝同一套渐变。
- **中心圆是一张白色渐变卡片**（HTML `div`，不是 SVG 圆）：发丝描边 + 小偏移投影 + 内高光，
  顶上再补一道竖向高光当「玻璃感」。不用 `backdrop-filter`（理由见下一节），
  投影也必须「往下落」而不是「往外扩」—— 大模糊 + 高浓度会在圆周围糊出一圈灰环。

- 图标从 r=157 收到 152，名字正好落在花瓣的高不透明度段上；名字 12px / 600 再加一圈白晕
  （`text-shadow`），深底浅底都读得清。**选中时名字不变蓝**：名字那一段的蓝色已经很淡，
  蓝字压在淡蓝上等于没有对比度，改用深靛蓝（夜间用近白）。

- 中心提示允许折两行：「已在当前页 · 松开收起」在 184px 的圆里一行放不下，
  截断成「已在当前页…」反而看不懂；文案也顺手收短成「已在当前页」。
- 指针死区跟着中心圆走：`indexFromPoint(dx, dy, hubRadius)` 现在要传中心圆在屏幕上的
  像素半径（由调用方按 `min(440px, 74vmin)` 换算），不再是写死的比例。
- 设置面板里的轮盘预览同步换了几何（花瓣 + 中心圆 + 角缝隙），预览与实际一致。

## 新增 · 轮盘外也一起虚化


- 轮盘展开时，**整个页面也会被糊掉**（`quickWheel.css` 的 `.scrim`）：一层全屏毛玻璃 +
  14% 暗色，只留圆盘是清楚的 —— 就是参考图里「世界虚化、只剩轮盘」的那种感觉。
  之前只有圆盘自己在模糊，四周页面还是清晰的，反而显得圆盘像贴上去的一块板。
- 模糊强度跟「轮盘背景」那个滑块联动（×0.8：圆盘 24px → 背景 19px），不另开设置项；
  材质关掉时这层也一起消失（实色圆盘 + 原样页面）。
- **它必须是 `.disc` 的兄弟，不能当祖先**：带 `backdrop-filter` 的元素会成为后代的
  「背景根」，套在圆盘外面的话圆盘自己的模糊就只能采到这一层内部（等于空的）。
  这和「淡入不能挂在 opacity<1 的祖先上」是同一条规则的两种表现形式。
- 夜间那层暗色加深到 30%（`rgba(0,0,0,.3)`），否则深色页面上圆盘会糊成一片。
- 代价：全屏 `backdrop-filter` 比只糊一个圆盘贵，所以它只在按住呼出键的这一两秒里存在，
  松手立刻撤掉。

## 修复 · 「轮盘背景」看起来没生效


两个原因叠在一起，都不是「参数没传进去」（实测 `is-glass` 类、CSS 变量、`backdrop-filter`
全部正确），而是「传进去了但看不出来」：

- **默认遮罩 86% 太实**：圆盘几乎是块不透明的白片，模糊在视觉上完全不存在，拖「模糊强度」
  0 → 60 一个像素都不变。改成 **61%**（和搜索面板 / 触发面板同一档），才既能看出是毛玻璃、
  图标和名字又还清楚。已经存过 86% 的（只有开发期试出来的那份）会被 `epoch` 记号自动换成
  新默认，自己调过的值不动。
- **淡入做在了 `.stage` 上**：祖先 `opacity < 1` 会形成「背景根」，圆盘的 `backdrop-filter`
  在那 160ms 里只采得到 `.stage` 内部（等于空的）—— 展开瞬间是一块没有模糊的实色片，
  最后一帧才「啪」地糊上。修法是把透明度过渡挪到 `.disc` 自己身上（元素自身的 opacity
  不影响自身的 backdrop-filter），`.stage` 只负责 `visibility`。这条和面板、顶栏那几处
  「淡入要挂在带 backdrop-filter 的元素自己身上」是同一个坑。
- 顺带把名字调深、加粗（`#33333a` / 600）：遮罩降下来之后底下压什么颜色都可能，
  11.5px 的浅灰字在深色画面上读不清。

## 技术细节 · 几处容易踩的地方


- **`panelButton.css` 也要藏 `.wheel-editor`**：`panel.css`（近千行、7 处 backdrop-filter）
  是首次打开面板才注入的，在那之前编辑器标记是「无样式的裸 DOM」，不藏住会直接在右下角
  铺一片文字。这条和 `.panel` / `.confirm-mask` 是同一个原因。
- **SVG 元素别用 `shadow.getElementById`**：它按 `HTMLElement` 推断类型，转 `SVGGElement`
  会被 TS 判成「类型不重叠」。改用 `shadow.querySelector<SVGGElement>('#wedges')`。
- **存储结构从「列表」换成「定长槽位数组」**：`bili-elite-wheel` 里的 `slots` 恒为 8 项、
  元素可为 `null`。旧的 `items`（1.1.2 开发期内的临时结构）没有槽位语义，读到会直接用默认。
