# 1.1.7

> 小版本：新增「界面优化 → 顶栏优化」——整条顶栏由扩展自己画，打开网页第一帧就在，
> 不再等 B 站那套 header 脚本。搜索面板（历史 / 热搜 / 联想）和右侧图标区都是我们自己的。

## 新增 · 顶栏优化（界面优化，默认开启）

**问题**：顶栏什么时候出现，完全由 B 站的 `bili-header.umd.js` 决定。实测（playwright +
真实构建产物，1600×900，BV1Qgn96oEUz）：

| 时刻 | 顶栏状态 |
| --- | --- |
| 485ms | 我们的骨架栏就位（只有 logo + 两块灰块） |
| 750~950ms | 首帧绘制 |
| **4511ms** | B 站顶栏的导航 / 搜索框 / 右侧图标一起出现 |

把扩展整个关掉量同一页面：导航项 **5060 / 5432ms** 才出现 —— 慢的不是我们，是 B 站自己的
顶栏渲染。1.1.6 把骨架栏升级成「顶栏壳」只能改善观感；要真的「打开就有」，只能整条自己画
（BewlyCat 就是这么做的：`#bewly` 是它自己的树，从不等于宿主的顶栏脚本）。

### 结构（`selfTopbar.ts` + `selfTopbar.css`）

- 宿主 `#bili-elite-tb` 挂在 `<html>` 下（和骨架栏同一层），`document_start` 就建好；
  开关一关整块移除，样式表也一起摘掉。
- 左：logo（96 宽，让「首页」落在 x=120）+「首页 ∨ / 动态」。
  首页那个 ∨ 悬停展开频道面板 —— **复用已有的 `#bili-elite-home-panel`**
  （同一套 DOM 结构、同一套材质 / 夜间样式，只是改成挂在我们自己的 `.tb-home` 里）。
- 中：500×40 的搜索框，绝对居中于整条 bar；点开是搜索面板：
  **搜索历史**（`chrome.storage.local`，跨 www / search / t 三个子站共用一份，最多 10 条，
  可清空）+ **热搜**（`x/web-interface/search/square`）+ **输入联想**
  （`s.search.bilibili.com/main/suggest`，命中字自己包 `<em>`，不用接口返回的 HTML）。
  键盘 ↑↓ 选择、Enter 搜索、Esc 关闭；点击外部 / 页面滚动也会关。
- 右：**登录 / 头像 → 消息 / 动态 / 收藏 / 历史 → 投稿**，顺序与原生完全一致。
  数据走 `x/web-interface/nav`（头像、mid）与 `x/msgfeed/unread`（未读总数，>99 显示 99+）。
  未登录时是蓝色人像圆 +「登录」，点进 passport；已登录时头像点进个人空间、收藏指向
  `space.bilibili.com/<mid>/favlist`。

### 与原生顶栏的关系

- 原生 `.bili-header__bar` 只做 `visibility: hidden`（topbar.css §1.0）：**它仍然占着文档流里
  那 64px**，所以开关来回切页面不会跳（用 `display:none` 会让 `#mirror-vdcon` 上移 64px）。
- 原生顶栏那套补丁在开关打开时全部停手（`syncChrome` / `sync` 里两处提前 return）：
  骨架栏、自绘 logo、番剧改名「动态」、原生频道面板、右侧隐藏、搜索页关键词 —— 都由新模块
  自己实现，再改一遍只会改到看不见的节点上。
- 搜索页：地址栏 `keyword` 回填到我们自己的搜索框；页面自带搜索框与滚动后的吸顶搜索条
  一起收起（否则会有两条）。

### 一致性（都按原生量过，1584 视口）

| | 自绘顶栏 | 原生顶栏 |
| --- | --- | --- |
| 首页 | 120 / 43 | 120 / 43 |
| 动态 | 178 / 28 | 178 / 28 |
| 搜索框 | 534,12 / 500×40 | 534,12 / 500×40 |
| 右侧图标 | 1193…1443（5 × 50）+ 投稿 1453…1543 | 同左 |

- 材质（顶栏 / 搜索框 / 搜索面板 / 触发面板）、顶栏渐变、夜间模式、奶睿顶栏图全部接上，
  取值与原生那套同一组 CSS 变量 —— 开关一关，观感应该看不出换了一套。
- 窄窗口照原生那套收缩：≤1280 图标压到 25px、投稿变成 34px 的图标按钮、搜索框按
  `100vw − 500` 收窄（实测 800~1400 五种宽度下与右侧图标区永不重叠）。
- 网页全屏 / 原生全屏整条让位（topbar.css §13）；层级 1002，设置面板仍在最上面。

### 已知差异（本次没做，下一步候选）

- 右侧图标**没有悬停浮层**：原生的「消息 / 动态 / 收藏 / 历史 / 头像」悬停会弹出最近内容，
  这里点一下直接跳转到对应页面（未读数、头像、链接都正常）。要做浮层需要
  `history/cursor`、`fav/resource/list`、`dynamic/feed`、`space/wbi/acc/info` 几个接口，
  其中两个还要 wbi 签名，单独一轮再做。
- 搜索页提交是整页跳转（原生是站内 SPA 切换）。搜索结果本身不受影响。

### 验证

- 几何：1584 下逐项与原生一致（上表）；1000 / 900 / 800 宽无重叠、无多余占位圆点。
- 交互：热搜 10 条、联想 10 条、↑↓ 选中第 1 条 Enter 跳到 `all?keyword=猫和老鼠`、
  搜索页回填 `猫和老鼠`、历史跨页保留并可清空、Esc / 点外部 / 滚动都能关面板。
- 频道面板：45 个链接、位置 `[24,72]`、宽 769，悬停展开正常。
- 开关：关掉后 `#bili-elite-tb` 移除、`bili-elite-tb-on` 摘掉、原生顶栏恢复、骨架栏回来；
  个人空间 / 直播 / 历史记录三处按原约定整套不接。
- 首页 / 搜索页 / 视频页布局与开关关闭时逐项相同（`.bili-header` 64、`#mirror-vdcon` 64、
  `feed` 64）；videoBeta 的 `up.top − title.bottom` 仍是 8。
- 夜间 / 无材质两种配色都截图核对；`tsc --noEmit` 只剩 3 条既有报错。
